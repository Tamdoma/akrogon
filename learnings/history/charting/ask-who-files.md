# Ask who files and from where before shaping intake

Both slots shaped GitHub Intake around a person typing an issue. The operator then said colleagues file through agents, from client projects where the framework is installed, about bugs that belong upstream. That one fact changed the target rule, kept a skill both slots were ready to drop, and added the pull mirror.

Rule: an intake decision starts by naming the filer, the tool they file with, the repo they stand in, and the repo the report belongs to. When any of the four is unknown, ask before the batch. The operator holds these facts and the codebase does not.
