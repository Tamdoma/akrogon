# Handing a session off before a clear

## What was not good
The operator wanted to clear mid-flow. A decision had just been claimed, the challenge check was half answered, and the next prompt was in nobody's head.

## What the updated way does
Before a clear: set any claimed decision back to open, write unanswered challenge items into CHART.md so the next session sees them, confirm the working tree holds everything, and give the operator one paste-ready prompt naming the lane, the decision to take, where slot B lives, and the one thing to look at.

## Why
Chat is the only state that dies on clear. Everything else is files. The paste-ready prompt is the handoff line the intake asks agents to leave for each other, applied to the operator.

## How it gets improved
If the next session still has to ask what to do, the prompt was too thin. Add what it asked for to this file.
