# Name the reader before placing an artifact

Both slots proposed a file for the "Last operation" and "Next" lines in Handoff Location. The operator asked who would read it. The next pass already gets its prompt line, the state file and the leaf files, so the file had no reader, and the decision collapsed to printing the lines.

Rule: before asking where an artifact lives, name who reads it and what they already have. If every reader already holds the content another way, the question is not where but whether. Check this before the batch, not after the operator asks.
