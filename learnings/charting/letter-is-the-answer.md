# The letter is the answer, the question is not

## What was not good

The operator replied to a batch with letters on seven questions and explanation requests on two. Slot A explained, then wrote all nine as accepted and moved to resolve. Two decisions were never made.

## What the updated way does

A letter with a question attached is an answer plus a request to explain while work continues. A number with a question and no letter is an open question. The decision resolves only when every material question carries a letter. Slot A never fills in a letter from its own explanation.

## Why

Operator, 2026-09-08: "Resolve only the things where they are settled by me actually putting the letter. If I put the letter in, that means that I agree with that answer but I need some explanation so you can continue while I'm reading. But if I haven't put the letter, I still need to decide."

## How it improves the process

Explanation and decision are separated by one visible token, so the operator can keep reading while lettered work proceeds and nothing is decided on their behalf.
