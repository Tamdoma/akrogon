# Chart: optional charting peer C

## Destination
When the operator names a C pane at chart open (beside B), chart-issues runs C as an extra charting peer. Without a C pane, charting behaves as today. C never appears in lifecycle phases, config or state.

## Forks taken
- [Peer shape](forks/peer-shape.md): C copies B's full charting role, blind to A and B, named only with B.
- [Merge record](forks/merge-record.md): tags list the agreeing slots, e.g. `(B,C)`; `(both)` retires.

## Open forks
None.

## Fog
None.

## Off route
- Config key or election question for C: door-second-slot foreclosed both for B; the pane name is the election.
- Command, dispatch or state changes: C lives only in the door; lifecycle tabs stay two panes (seat-guards).
- plan-issue, implement-issue, check-issue: operator limited C to charting.
- The debate field: naming peers never sets it (debate-count).
