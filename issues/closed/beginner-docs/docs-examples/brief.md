# Brief: docs-examples

## What

Real stories under docs/examples/: README.md, quick-fix-story.md (direct route), autopilot-story.md (autopilot charting into lifecycle), recovery-story.md (varhop, a failed leaf carried forward into a landed redo).

## Why

The operator asked for real-life use cases from projects outside Akrogon. Each story shows a different way of working and links the current how-to and reference pages. Links docs/use/ pages from docs-use-plan and docs-use-finish, docs/reference/ pages from docs-reference-commands and docs-reference-records, and pictures from both picture leaves.

## Done-criteria

1. Each story is based on the record named for it in the private provenance file, re-checked by the implementer to have landed on that project's main before it is told; the varhop failed-versus-merged record conflict is resolved from its records and told accurately.
2. No story contains a private project name, client name, other person's name, home path, private repo name, session id, secret or date; varhop is named and links its public issue and commits; seat B reviews every page's text, links, alt text and images against this list.
3. Each story says what happened in plain words using today's commands, quotes recorded output only where it matches today's tool, and links the current use/ and reference/ page for each step; it is not written as instructions.
