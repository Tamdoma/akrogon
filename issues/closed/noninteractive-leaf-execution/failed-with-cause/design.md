## Leaf architecture
Owned: src/akrogon.ts (strict argument parsing accepts `--reason <text>` for `phase` and forwards it; (B) F1), src/routing.ts (add `failed` to every active phase's `next`; add `check.fix` to failed's `next`), src/state.ts (optional strict `failure` object: `cause` enum `blocked | attempts`, `phase`, `slot`, `reason` non-empty string, `delivery` optional string reserved for failure-attention), src/phase.ts (`phaseCommand(repo, slug, requested, slot, verdict, reason)`; `transition` takes `reason` and, when `requested === 'failed'`, runs the stop path: validate that `slot` is required and not in `done`, skip `requireClean`, `requireNoIssueFiles`, `requireNonEmpty`, the rebuttal destination check, the verdict requirement, the two-seat completion barrier and the review destination override, then `commitMove` with `failure` (B) F2; when `state.phase === 'failed' && state.failure?.cause === 'blocked'` skip `requireClean`; the move out of `failed` removes `failure` (B) F3; review repair exhaustion at the existing fix-rounds cap passes `{ cause: 'attempts', phase: 'check.review', slot, reason: 'fix rounds exhausted' }` (B) F3; `commitMove(repo, leaf, state, phase, slot, failure?)` clears `busy_since`, `busy_notified`, `prompted`, `prompted_at` on `failed` and `merged` and writes `failure` when given; existing callers omit the sixth parameter), src/next.ts (`activeCount` excludes `failed` in the readable filter and in the unreadable branch, which counts `leaves.filter(phase !== 'failed').length + unreadable` (B) F4; `dispatchLeaf` skips seat observation for `failed` as it does for `merged` (B) F6; the attempts-cap `commitMove` passes `{ cause: 'attempts', phase, slot, reason: 'attempts exhausted' }`), src/status.ts (`note()` prints `failed <cause> <reason>`, `failed` alone without `failure`, and no busy age for failed or merged leaves), tests for each.
Interfaces: `commitMove(repo, leaf, state, 'failed', slot, failure)`; `akrogon phase <slug> failed --reason <text> [--slot <A|B>]`, `--slot` required exactly when the current phase requires two seats (B) F11; `--reason` refused on any other destination.
Exclusions: no herdr calls (failure-attention), no skill prose (skills-never-ask). `failed_notified` is left untouched here and removed by failure-attention.
Dependencies: none.
