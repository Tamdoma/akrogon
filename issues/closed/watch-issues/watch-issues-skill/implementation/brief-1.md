## 4. Change list and needed interfaces

New files only, all under `skills/watch-issues/`:

- `package.json`: name `@akrogon/watch-issues`, `private`, `type: module`, deps `zod ^4.6.1`, dev `@types/bun ^1.4.2`, `typescript ^7.0.2`, scripts `test: bun test scripts/observe.test.ts`, `typecheck: tsc -p tsconfig.json`.
- `tsconfig.json`: copy `skills/broadcast-issue/tsconfig.json` verbatim.
- `bun.lock`: generated by `bun install --cwd skills/watch-issues`.
- `scripts/observe.ts`: `bun observe.ts <root>`:
  - Resolve the repo key: spawn `[process.env.OBSERVE_AKROGON ?? 'akrogon', 'config']` with `cwd=<root>`; non-zero exit or YAML without a usable `repo` (or `repo: none`) → exit non-zero naming the cause.
  - Walk `<root>/issues/open` recursively (missing dir → empty inventory, exit 0, no output). A directory containing `state.yaml` is a leaf; validate depth 2 or 3 under the `open` root, parse YAML, strip the three legacy keys, validate with a local `strictObject` zod schema mirroring `src/state.ts` field names (slug, phase, created, repo, debate, `blocked-by`, sources optional, hand_built optional, busy_since, busy_notified, attempts, done, fix_rounds, verdict, tab, worktree, pane, prompted, prompted_at, delivery_error, failure optional) including the duplicate-`done` refine. Any read/parse/schema failure → exit non-zero naming path and cause. `state.repo !== <repo key>` → exit non-zero naming path, stored key, registered key. Duplicate slug across leaves → exit non-zero naming it.
  - If at least one leaf exists, spawn `[process.env.OBSERVE_HERDR ?? 'herdr', 'agent', 'list']` once; non-zero exit or stdout that is not JSON with `result.agents` → exit non-zero naming the cause. Build a `pane_id → agent_status` map.
  - Print one line per leaf, sorted by slug: `slug=<slug> phase=<phase> attempts=A<n>,B<n> blocked=<comma-joined blocked-by|empty> A=<pane|->/<status|->[+HhMMm] B=<pane|->/<status|->[+HhMMm] notified=<comma-joined seats with busy_notified|empty>`; when `phase=failed` append ` failed=<cause>@<phase> delivery=<delivery|-> reason="<reason>"`, or ` failed=unknown` when `failure` is absent. Busy age suffix `+HhMMm` appears only when `busy_since[seat]` is set (`now - Date.parse(value)`, hours not zero-padded, minutes two digits, e.g. `+0h14m`). A seat with no recorded pane prints `-` for pane and `-` for status; a recorded pane missing from the agent list prints the pane id and `-` for status.
- `scripts/observe.test.ts`: bun:test; each test builds a scratch root (`mkdtempSync`) with `issues/open/<owner>/<slug>/state.yaml` fixtures and a fake `akrogon`/`herdr` via `OBSERVE_AKROGON`/`OBSERVE_HERDR` pointing at small fixture scripts you write under the test's scratch dir (a `config`-printing stub and a JSON-emitting `agent list` stub; a failing stub for the error cases). Assert exact stdout lines and exit codes.
