## D1. The leaf as picked ships no proof for the store half of the outcome

The intake's outcome has two clauses: "a test run leaves no host dir under the leaf temp root **and no dir under the real worktree store** behind." A's picks cover the first clause end to end: proven mechanism (1a), boundary test red-on-base (3a). For the second clause the picks contain nothing: 2a records non-reproduction under Off route, 3a's boundary test exercises only the temp root, and fork 4 excludes every store-adjacent extra. "Not reproduced by four slots" is evidence about current code, not verification of the outcome — it cannot distinguish "no live path exists" from "a rare path exists that our probes missed" (the leak rate was about 35 dirs in two days against thousands of test-file executions; my own probes of the temp leak also flaked between runs of the same file, O7).

Evidence that a proof is cheap and does not require reproducing the original leak: `akrogon config` prints the resolved `worktree_store` (docs/reference/files.md, `src/config.ts` `effectiveConfig` emits `worktree_store`). A boundary test can spawn the CLI for a fixture repo the way the suite's own spawns do (`AKROGON_HOME` and `HOME` set, the exact env construction `cli()` uses), assert the resolved store is inside the fixture-controlled tree, and assert nothing appears at the passwd-home store path for that fixture's repo name. That pins the correct-behavior chain (env construction → CLI → store resolution) the same way 3a pins the temp chain, is deterministic, free, and is red the day any future env-filter change breaks HOME propagation for store-resolving commands — which is the only leak shape ever observed for clause 2.

Consequence if built as written: the leaf either silently narrows the outcome (a chart-level decision the door, not the leaf, owns) or claims clause 2 with zero evidence. Either way, if the store leak's real path is still alive in current code — unattributed, not disproven — nothing in the shipped leaf detects its return, and the class regenerates the same intake in a month. Cost of the fix: one boundary test beside the 3a test, no product change, consistent with pick 2a.
