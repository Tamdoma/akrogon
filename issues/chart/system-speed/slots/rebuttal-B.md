Eleven failed moves include repeat leaves, so they are not eleven independent opportunities, and there is no justified whole-cohort saving yet.

Reuse the current phase/resume commands after a reasoned, evidenced resolution.

Reassess any independent outer deadline before choosing a resumable wait. Batching remains approved, outside this new ranking.
