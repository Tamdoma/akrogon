## 2. Rules/fields that force the implementer to guess or clash with records
- **Empty-bucket medians on the real marker (`brief.md:14`):** At `--since 2026-10-15T07:25:26Z` (`design.md:7`), the on-or-after bucket has `0` merged issues (and `0` issues handed off after `07:25Z`). `brief.md:14` does not define what `median wait`, `median total over merged issues`, `median fix rounds`, or `backlog` ages print when a bucket or merged subset is empty (e.g. `none` or `-`), nor how even-count medians of integer days / fix rounds format.
- **Same-day `--since` coarsening (`design.md:7,40`):** `design.md:40` splits before/since by comparing `created` (`YYYY-MM-DD`) with the UTC date of `--since` (`2026-10-15`), which misclassifies leaves handed off earlier on `2026-10-15` *before* `07:25:26Z` (such as `stacked-turn`, `created: '2026-10-15'` at `06:24Z`) into the "on or after `--since`" bucket. When `log.jsonl` has a leaf's first event timestamp (or first `timings.jsonl` `visit_start`), comparing that timestamp against `--since` (falling back to `created` only when absent) avoids same-day bleed.
- **"median fix rounds per leaf" in multi-leaf / multi-source issues (`brief.md:6,14`):** In `akrogon`, `44/75` handed-off issues span multiple leaves and leaves can carry multiple `sources`. `brief.md:14` does not state whether the summary's *"median fix rounds per leaf"* is the median across distinct leaves in the bucket or across issues (`fix_rounds / leaf_count`).
- **Units, sort order, and parked leaves (`brief.md:6,12-13`, `design.md:25,34`):** `src/timing-report.ts:202` `duration()` formats `XhYmZs` (no days), whereas `brief.md:6` uses whole days for `wait` and leaves the unit of `total` and backlog `age` (and backlog sort order + same-timestamp tie-breaker) unstated. Also, `allLeaves(repo)` (`src/state.ts:143`) reads only `open` and `closed`, so any leaf in `issues/parked/` (`src/state.ts:156`) would be missed and listed as unhanded backlog.

## 3. Simpler view / low-value columns
- **Drop the per-issue unsourced-leaf count line (`brief.md:12`) and use consistent units:** Unsourced leaves have no GitHub filing time and are already covered by `akrogon timing --cohort`; omitting the extra unsourced-count line (or folding it into the header) and formatting all issue-level spans (`wait`, `total`, backlog `age`) in one unit (`duration()` or `Xd`/`Xh`) removes unit mixing.
