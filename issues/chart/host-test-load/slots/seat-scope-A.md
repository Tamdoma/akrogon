# Notes A: seat-scope (before reading B/C)
Pick: pane shell, adopted before `herdr agent start`. Layout: `akrogon.slice` (CPU weight) > per-leaf `akrogon-<repo>-<slug>.slice` > one scope per pane, `akrogon-<repo>-<slug>-<A|B>-<pane>.scope`, created from `herdr pane process-info --pane <id>` shell_pid right after the pane exists (src/next.ts:466-527) and before agent start (609-647). The shell is idle, so nothing is born outside. Bus cut joins the placement env list (src/next.ts:453-464, `--env DBUS_SESSION_BUS_ADDRESS=unix:path=/nonexistent`), so the shell and every later seat inherit it. A replaced seat in the same pane stays inside; a new pane gets its own scope at its split. Stop = stop the leaf slice: pane shells die, herdr pane ends, dispatch rebuilds as for a lost pane.
Rejected seat-process adoption: harness children during init can be born outside (B round-1 R2); scope dies at each seat restart.
Rollout: existing tabs are outside until recreated; adopt them by a one-time move of the shell plus all current descendants (StartTransientUnit PIDs takes a list), or accept until the tab is replaced. Prefer the one-time move with a re-scan until stable.
Evidence: herdr 0.9.1 process-info shell_pid (checked 2026-10-13); src/next.ts placement; systemd.io CONTROL_GROUP_INTERFACE PIDs.
Pitfalls: operator typing in a leaf pane is inside the fence (accept, named); pane shell PID reuse race (validate pid start time before adoption); private manager socket for the call (proof pending).
