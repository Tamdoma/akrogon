# Slot C final-shape check: auto-remove

1. Item 3a deletes the branch by name with `git branch -D` after the worktree removal, which is not bound to the head the 2a proof covered. Between the proof and the deletion the removed record already captures the proven head from the porcelain read (src/reconcile.ts:548-550), but once the worktree is gone the branch is free: another process can check it out elsewhere or advance it with a commit `git cherry` never saw, and a by-name `-D` then deletes that newer tip unproven. Today's only branch deletion uses `-d`, whose merged-check revalidates at deletion time (src/reconcile.ts:552-562); `-D` has no such guard. Exact fix: replace the `-D` step in item 3a with a compare-and-delete against the proven head, `git update-ref -d refs/heads/<branch> <proven head sha>`, keeping `-D`'s effect when the tip is unchanged and keeping the branch with a reason when it moved.
