Keep logical B/C identities across new pane IDs, collect the prior exchange first, and never resurrect a consultant already dropped by autopilot. Evidence: `issues/chart/chart-peer-panes/forks/peer-panes.md:18`, `skills/chart-issues/SKILL.md:25,139`, `assets/questions.md:46`; commands `herdr pane close --help`, `herdr pane split --help`, `herdr agent start --help` confirm separate close/split/start operations and forwarded agent arguments.
