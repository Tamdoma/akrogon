## Q1 Base fix path
- **Pick:** Build any base fix in a clean disposable detached worktree created from freshly fetched `<remote>/<default_branch>` outside git (e.g. under `/var/tmp` or `<case-folder>/worktree`, never editing `repo.root`), touching no `issues/` or `.env`, run the failing command plus `checks` and `merge_checks` (per `consult-loop` item 9, using `repo.config.setup` when set and honoring `merge_covers` and grant bounds), and push fast-forward only (`git push <remote> HEAD:refs/heads/<default_branch>`). On non-fast-forward rejection (a concurrent merge landed first), fetch, rebase onto the new remote tip, re-verify the new tree, and retry fast-forward push (up to 2 retries; re-evaluate with watch on conflict/new red); always `git worktree remove` on finish or cleanup. Reason: isolates base fixes from dirty operator checkouts/local `issues/` in `repo.root` and serializes cleanly with `src/phase.ts` `batchPush` and `skills/merge-issue/SKILL.md` `## merge` without force-pushing (S3). Cost: one extra `git worktree add/remove` and `setup` run per base fix.
- **Rejected:** Editing `repo.root` directly (risks clobbering uncommitted operator work, pushing wrong branch, or committing `issues/` to `main`); pushing after non-fast-forward rebase without re-verifying (violates `consult-loop` item 9); force-pushing (violates S3) or inventing a separate push lock (deadlock risk when `batchPush` already serializes on the remote ref).
- **Evidence:** Direct code (`src/seat.ts` `startConsultant`; `src/phase.ts` `batchPush`, `requireNoIssueFiles`; `src/config.ts` `setupCommand`; `skills/merge-issue/SKILL.md` `## merge`, 2026-11-21); Locks (`forks/signposts.md` `## Taken` S2/S3; `forks/consult-loop.md` `## Taken` item 9, 2026-11-21).
- **Pitfalls:** Orphaned worktree after consultant crash/stop -> record worktree path in `case.md` so watch removes it (`git worktree remove --force`) during reconcile/close; `full` suite contention with active seats -> run through `akrogon run-check` where applicable so `full` serialization holds.

## Q2 Leaf-local fix

When the leaf has no worktree yet (e.g. `plan.synthesis`) or needs broader rework, the consultant advises and the watch recovers the leaf back into its work phase for its own seats. Reason: directly satisfies Lock 2 S2 (2b) so leaf defects past the 2-cycle cap can actually be fixed while preventing concurrent-seat git races and honoring all `moveGuards`. Cost: consultant must obey trailer, clean-tree, and brief-scope rules.
- **Rejected:** Always delegating leaf fixes to the leaf's own seats (violates Lock 2 S2 and repeats failures that already hit the 2-cycle recovery cap); editing a worktree while a leaf seat is `working` (corrupts git state); letting the consultant edit `brief.md`/`design.md`/`state.yaml` (violates S3 and `Never`).
- **Evidence:** Direct code (`src/phase.ts` `moveGuards`, `requireClean`, `requireNoIssueFiles`, `requireTestChangeCitations`, `requireFrozenCitations`, `transition`, 2026-11-21); Lock (`forks/signposts.md` `## Taken` S2/S3, 2026-11-21).

## Q3 Resume
- **Pick:** Only the watch runs `akrogon phase <slug> <target-phase>` (omitting `--slot`) then `akrogon next <slug>` once every required seat of `<target-phase>` is idle or absent. Reason: today `commitMove` keeps `recorded.batch` on `leavingFailed`, and `src/next.ts` `reconcileBatch` returns early for `phase === 'merge'` when `candidate === undefined`, causing `mergeTurn` to re-dispatch seat B on the stale pre-fix `attempt`/`top` (`wake=red`) instead of rebasing onto the consultant's new `main`. Cost: ~2 lines plus test in `src/phase.ts` `commitMove`.
- **Rejected:** Consultant calling `akrogon phase`/`next` directly (splits lifecycle ownership and breaks stop/crash reconciliation); moving `failed -> merged` (illegal in `src/routing.ts` `routing.failed.next`); leaving `commitMove` unchanged (replays stale `batch` on `failed -> merge` before `reconcileBatch` clears it).
- **Evidence:** Direct code (`src/routing.ts` `routing.failed.next`; `src/phase.ts` `commitMove`, `transition`, `moveGuards`; `src/next.ts` `reconcileBatch`, `mergeTurn`, 2026-11-21); Locks (`forks/signposts.md` `## Taken` S2; `forks/consult-loop.md` `## Taken` items 8, 11, 2026-11-21).
