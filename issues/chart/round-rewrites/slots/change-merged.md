## 1 · How does the door get second-version quality on the first print?

- 1a (A,B) The existing pre-send read becomes a rewrite of the finished draft: simpler words, less repetition, same structure, every required element kept, and concrete context for each choice and what follows from it. Only the rewrite is printed. If the skill is edited, the instruction replaces the existing read-once sentence; no new check, step or round type is added. (A) Cost: one more writing pass per round, a median of 776 output tokens per alias rewrite today; the operator's alias turn goes away. (B) The added reasoning cost of doing it before printing is unmeasured.
- 1b (A,B rejected) More "write simply" wording, one pass. The rule already says it. (A) One-pass rounds written "at the `elid` level" got `elid` on 3 of 3 rounds in this session.
- 1c (A,B rejected) A separate rewriting seat, agent or call. Adds a part and, as a model call, an unapproved paid operation.
- 1d No skill edit if the current instruction, applied this way, succeeds. (B) keeps it available: permission to edit does not prove an edit is needed. (A) rejects it as the end state: a rule that worked only when a door chose to read it this way fails again in the next door; the sentence that exists today is the one being replaced.
- Evidence: (A) 52 of 64 rewritten rounds were answered after the first rewrite, against 18 of 82 first prints. (B) M33: 1252, 1092, 497 words, then a 421-word location and edit list before the answer; definitions and shortening alone failed. (A) Anthropic, "Prompting best practices", "Chain complex prompts": draft, review against criteria, refine. (A,B) Anna Kaley, NN/g: the user's concepts and order. (A) Heath and Heath, HBR 2006, the curse of knowledge. (B) None of this shows self-revision succeeds reliably.
- Pitfalls: (A,B) the rewrite changes a choice: compare choices, numbers, costs, disagreement and drawings before and after by meaning; a change is a reshaped proposal. (A,B) "simpler" is not metaphor. (A,B) the skill states the instruction itself and does not depend on the operator's private alias file. (A) the draft is scratch and is discarded, so no second full-round file enters the chart. (A) no word number is stated.
- Unasked: (B) record which concrete defect the rewritten draft fixed, with the operator's response, before the edit.
