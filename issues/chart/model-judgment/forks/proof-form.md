# proof-form

## Question

1. How is a model-choice criterion marked, recorded and planned?
   - 1a (recommended) Marked by its wording at charting (who decides, on what evidence, where the choice and reason are recorded), no tag or field. Record lives in an artifact the work already writes; function checks only (exists, keys and states valid, references resolve, reason not blank; never the reason's length, words or format). plan-issue gets one governing paragraph before its per-condition and test-writing paragraphs: the record takes cases, the choice takes no test, case or deliberate break; plan.md names the run the leaf makes anyway or its recording, the record and output paths the review seat reads, and what stays unproven; this is not new proof machinery. A sourceless count, share, score or text match in a criterion is read in this form by the earliest seat (the planner, in plan.md), its function checks kept, no case for the number. The planner never relabels a criterion with a named one-right-answer source as a choice.
   - 1b A tag or schema field marks choice criteria.
   - 1c No mark; each seat classifies again.

## Findings

- Marking by wording (B K2a); 1b is the first thing a script would key on (B); 1c lets a planner drop a real test (B).
- Record in existing artifacts, no shared shape (A,B,C); fixed shape invites a validator (B K3c, C F3 O2).
- Governing plan paragraph (A,B,C; framework D rebuttal text). Without "not new proof machinery" the plan pass fails (C F5, D).
- B rebuttal D1: the earliest seat applies the reading in plan.md, or the planner writes red-first tests for the count, tests lock, and every such leaf opens a repair round; "never relabel" must not ban the other direction, since a sourceless count is not one-right-answer under signpost 1a.
- check.review launches nothing, so the report names record and run output paths (B Q2).

## Taken
