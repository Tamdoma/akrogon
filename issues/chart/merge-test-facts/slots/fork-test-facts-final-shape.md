# Fork test-facts, proposed final shape (A's pick under full autopilot, 2026-11-25)

Round: fork test-facts, round 1 (Q1-Q4). Corrections against the merged notes are marked [changed].

1. Durations (Q1a). Each finished command row built from its own output gets optional `durations: {name, ms}[]`: the 20 slowest Bun-timed tests of that output plus every name in that leg's `failures` that has a timed line [changed: K = 20; failures always included]. `ms` is a rounded non-negative integer. Names follow failureNames' rule exactly (bare title, `(unnamed) <innermost stream token>`); a name seen twice keeps its max ms. Only anchored Bun lines `[<chain> | ](pass|fail) <title> [<n>ms]` count; a line with no bracket stores nothing. Absent when no timed line parses. Blocked and reused rows never get the field.
2. Timeouts (Q2a). Optional `timeouts: string[]`, non-empty, unique, a subset of the same leg's `failures`: names whose own stream prints `  ^ this test timed out after <n>ms.` right after that stream's `(fail)` line. `(script)` and `(no test name)` never enter it. `failures` stays byte-identical to today. Written in every scope.
3. Rerun legs [changed: per leg]. Each leg's facts sit beside its own log: the first (full) run's `durations` and `timeouts` inside `rerun`, the rerun leg's own at top level, with the top-level `timeouts` a subset of the top-level `failures`. A reader wanting the full-suite list reads `rerun.durations` when `rerun` exists, else `durations`.
4. Scope (Q4b). `durations` only on merge-scope rows, base comparison (`compares`) rows included. Stated limit: in a repo whose leaf and merge command sets match, a green leaf row reused as the merge receipt carries no durations.
5. Join (Q3a). Optional `attempt` on the verify-runs row, copied in `runOnce` from the pass record's caller when present. Meaning: the attempt that launched the pass. `samePass` is unchanged [changed: stated meaning, no join-key change]; a later attempt that joins a live pass is recoverable by tree. A reused green receipt writes no row; `tested_top` joins it by sha.
6. One scan of a command output returns failure names, timeouts and durations, or failureNames stays the name source and the new parse reuses its line grammar (Open for the plan); either way `failures` output is unchanged.
7. Old rows parse unchanged: every new field optional (signpost 6a).
