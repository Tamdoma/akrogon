# Slot B eligibility rebuttal

F1. I disagree with adding a categorical refusal for a done-criterion that needs a live run or outside call. That is the same unresolved scope restriction as the inputs/grants ban, not a separate technical requirement. The intake preserves all gating (issues/chart/direct-mode/INTAKE.md:12), and standing-design.md:10,14 explicitly permits outside/live proof when the property requires it. If the operator chooses code-only direct work, the restriction is consistent. If the operator permits fully gated small operational work, this additional refusal would contradict that choice. Keep both restrictions together in the product choice. My position also permits charting proofs, provided their existing gates and cleanup hold. It does not treat any proof record as proof of eligibility.

F2. “Hard refusals checked mechanically” overstates the agreed implementation. No-leaf direct work has no state.yaml blocked-by field or emitted leaves to count. The relevant condition is whether the bounded outcome actually needs multiple independently delivered units or an unfinished dependency, which requires judgment before any draft records are produced (skills/chart-issues/SKILL.md:45; issues/chart/direct-mode/forks/container.md:19-23). Mechanical checks may verify recorded structure, missing inputs, or named seats. They cannot establish conceptual smallness or that the draft omitted no required decomposition. Preserve the semantic refusal without inventing a direct blocked-by schema or relying on a one-leaf count as sufficient eligibility evidence. My original notes explicitly rejected that shortcut.

F3. The combined route/debate question is an option, not a recommendation I endorse as written. Very small lifecycle issues currently skip the debate question and use no (skills/chart-issues/SKILL.md:69; assets/shapes.md:259). For such an item, ask only direct versus lifecycle when no applicable answer already exists. For larger lifecycle work, keep debate as the separate implementation choice where it is needed. Combining presentation can reduce a round, but should not add a debate choice that current rules deliberately omit. Preserve concrete authorization already supplied.
