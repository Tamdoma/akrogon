# Leaf review: slot C — direct-visible / direct-leaf

Defects found in `leaf-draft/ISSUE.md` and `leaf-draft/direct-leaf/{brief.md,design.md,readiness.yaml,state.yaml}`.

## 1. Done-criteria shape and proof defects (`brief.md` `## Done-criteria`)

- **Criteria 1, 3 and 8 name a test file (`tests/hc-fixture.ts`)**: `shapes.md` `## Leaf files` and `## Preflight and validation` refuse any done-criterion naming a test file. Remove `(tests/hc-fixture.ts)` from Criteria 1, 3 and 8 (it already belongs in `design.md` `## Standing design` and `readiness.yaml` `proofs`).
- **Criterion 10 cites a non-existent `checks` command (`docs-links`)**: Criterion 10 names `"the existing docs-links check in checks"`, but `issues/config.yaml` `checks` defines only `format`, `test` and `typecheck` (`tests/docs-links.test.ts` runs as part of `checks.test`, not as a separate `checks` entry).

## 2. `akrogon direct` interface gaps and contradictions with `Taken`

- **No input path for `state.sources` (`Taken` #1 & #8 vs `brief.md` Criterion 1 & `design.md` `Interfaces`)**: `Taken` #1 puts the chart's delivered `sources` in `state.yaml`, and `src/phase.ts` `completeOwner` / `completion` read `state.sources` exclusively from `state.yaml` to close GitHub issues and populate `state.broadcast.sources`. Because `akrogon direct <slug> --reviewer <address>` creates `state.yaml` on first run and takes no `--source` flag (and none of `ISSUE.md`, `brief.md`, `design.md`, `readiness.yaml` stores machine-parsed `sources`), `state.sources` is never written.
- **Owner-folder lookup unspecified on first run**: `design.md` `Interfaces` triggers first run `"when the state file is absent"`, while the verb takes only `<slug> --reviewer <address>`. `src/state.ts` `findLeaf` / `leafFolders` only discover folders already holding `state.yaml`. When `<chart-slug> !== <slug>` (as in `direct-visible/direct-leaf`), the verb's lookup across `issues/open/*/<slug>` (and refusal on zero or multiple matches) is unspecified.
- **Contradiction between `Taken` #2, `brief.md` Criterion 1 and `design.md` `Interfaces`**: `Taken` #2 says `"First run (state has no seat refs): refuses when the owner folder already exists open or closed"`, whereas `design.md` `Interfaces` says `"first run when the state file is absent"`, and on first run the door already created `issues/open/<chart-slug>/<slug>/` (so the owner folder always exists under `issues/open`). Criterion 1 also refuses only `issues/closed` twins and omits `issues/parked`, whereas `src/turn.ts` `twinConflict` checks both `closed` and `parked`.
- **Leaf `.env` missing from Criterion 1**: `Taken` #2 requires creating the worktree `"with the leaf env"`, but Criterion 1 does not check `.env` / `env_names`.

## 3. `state.created` format unspecified (`brief.md` Criteria 1 & 4, `design.md` #2 & #6)

- `shapes.md` `## Leaf files` (and `leaf-draft/direct-leaf/state.yaml`) writes `created` as a date string (`'2026-11-25'`), and `src/state.ts` `stateSchema` accepts any `z.string()`. Neither Criterion 1 nor `design.md` `Interfaces` specifies that `akrogon direct` writes a full ISO 8601 timestamp (`new Date().toISOString()`). Writing a date-only string makes `Date.parse(state.created)` resolve to midnight UTC, skewing `TIME`, `first_prompt` and `merges[].total_ms` in `src/status.ts` by up to 24 hours (or rendering `'-'` when `end < start`).
- `design.md` `Consumers of changed state` omits `src/timing-report.ts`, which slices `leaf.state.created.slice(0, 10)` for handoff dates.

## 4. Missed consumers of changed state and missing owned surfaces (`design.md` `## Leaf architecture`)

- **`src/reconcile.ts` `reconcileHost` (permanent slice keep on merged direct leaves)**: `src/next.ts` `reconcileRepos` passes `live = null` to `reconcileHost`. Inside `reconcileHost`, `view` is `match.leaf.state.tab === undefined ? panes : await repoView(match.repo)`, where `panes` is still `null` until `livePanes()` is called. For every direct leaf (`tab === undefined`), `sliceKeepReason` therefore calls `broadcastInProgress(leaf.state, null)`, which returns `true` whenever `phase === 'merged' && state.broadcast !== undefined` — keeping the leaf's slice loaded forever as `'broadcast in progress'` even after broadcast finishes.
- **`src/reconcile.ts` `broadcastInProgress` (repo-session `live` vs multi-session `akrogon direct`)**: `design.md` `Interfaces` resolves `seat.A` and `seat.B` across *all* live hc sessions (`sessions()`), not `repoSpace(repo).session`. Yet `broadcastInProgress(state, live)` scans only `live` (`repoTerminals(repo)` = `repoSpace(repo).session`) and matches only `t.address === state.seat.B?.address` without checking `t.session`. For direct leaves, `broadcastInProgress` must check `union` (all live sessions) and match both `t.session === state.seat.B?.session` and `t.address === state.seat.B?.address`.
- **`src/next.ts` `dispatchLeaf` (`ownPlace()` gating `observeBusy`)**: `dispatchLeaf` currently calls `ownPlace()` (`repoSpace(repo)`) and returns `'skipped'` before observing busy. For a direct leaf whose `seat.A`/`seat.B` already carry `{ session, address }`, `observeBusy` must query `terminal(ref.session, ref.address)` directly without requiring `repoSpace(repo)` (otherwise busy observation is skipped whenever `repoSpace` is absent or in another session).
- **`src/usage.ts` (`VERB_OPTIONS`, `USAGE_LINES`, `optionsFor`) and `docs/reference/commands.md` missing from `Owned surfaces` and Criterion 10**: `src/akrogon.ts` parses flags strictly via `optionsFor(verb)` (`tests/cli-help.test.ts`), and `tests/command-reference.test.ts` checks `docs/reference/commands.md` against every dispatched verb and its flags. Adding `direct` and `direct-drop` without updating both files will break `checks.test`.
- **`skills/AREA.md` and `skills/plan-issue/SKILL.md` missing from `Owned surfaces` and Criterion 10**: `skills/AREA.md` explicitly names `direct-guards.ts` (deleted by this leaf), and `skills/plan-issue/SKILL.md` still points direct-route proof-command corrections to `<chart>/direct/plan.md`.
- **`src/timing-report.ts` `--cohort` caller of `visitGaps`**: `src/timing-report.ts` calls `visitGaps` from both single-slug `visitLines` and cohort reporting; both callers need the leaf's `direct` flag.

## 5. Gaps between `Taken` and done-criteria (`brief.md` Criteria 5, 9 and 10)

- **Criterion 5 (`check.repair -> merge` refusal loophole)**: Criterion 5 states `"refused when the head differs from the recorded red top and accepted unedited after a red land exit"`, leaving untested the case where `state.merge_exit` is absent (after a `check.review` `fix` verdict) or has reason `gate`/`conflict`/`dirty`. Without explicitly requiring `state.merge_exit?.reason === 'red' && head === state.merge_exit.top`, A could move straight `check.review (fix) -> check.repair -> merge`, bypassing B's Fixes.
- **Criterion 9 (`direct-drop` skips proving run cancellation and slice stop, and omits owner capture lock / repeat-drop collision)**: `Taken` #3 requires `direct-drop` to cancel active runs and stop the leaf slice, yet Criterion 9 tests only `"with a finished run cancels nothing still running"` (deleting run cancellation and slice stop would still pass). Also `design.md` `Interfaces` names only the global lock, omitting `flockHold(resolve(owner, '.lock'), '-x')` and `enclosingCapture(owner)` (as `src/phase.ts` `completeOwner` uses to avoid racing an active `run-check` capture) and omitting destination handling if `<chart>/direct/<owner>` already exists from a prior dropped attempt.
- **Criterion 10 omits `Taken` #12 and #14 from required skill updates**: `skills/implement-issue/SKILL.md` (`### Direct form`) must instruct slot A to add `Test-Change:` trailers on newly added test files (otherwise `frozen: {}` refuses every direct leaf's move to `check.review`), and `direct-route.md` must include `Taken` #14's rule to wait for `broadcast pending` to clear and B's broadcast turn to end before reusing or restarting B.
