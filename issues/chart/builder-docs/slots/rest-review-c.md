## 1. Docs architecture
- The 13-page plan (`issues/parked/builder-docs-rest/guide-chapters/guide-chapters/brief.md` L9-17) misallocates setup and pads minor tools. `01-what-akrogon-is.md` repeats `README.md`'s intro/fit check while `02-install-and-repos.md` crams machine prerequisites, `~/.akrogon/config.yaml`, `akrogon install`, PATH, multi-repo mental model, `/init-akrogon`, and grounding into one overloaded page, violating the operator's request for an easy-to-follow install/setup process. `03-your-three-tabs.md` also duplicates `docs/guide/04-a-charting-session.md` L7-15, breaking `docs/reference/where-things-go.md` L16 ("One home per fact").
- Splitting `09-lifecycle.md` and `10-merging.md` makes merging look like a separate operator stage when merge holds no seat and runs automatically after `akrogon next` (`skills/merge-issue/SKILL.md`, `docs/reference/skills.md` L42-47).
- `13-other-tools.md` bundles 6 unrelated minor tools (`brief.md` L17), contradicting `issues/chart/builder-docs/forks/signposts.md` L36 ("non-important parts, just mention them"), duplicating `docs/reference/releases-and-updates.md` L60 + `docs/use/roll-back-a-release.md`, and forcing ~6 low-value SVGs under "a picture per section".
- **Proposed architecture (11 guide pages + slimmer `docs/reference/`, zero renumbering of `04`-`08`):**
  - `README.md` (what Akrogon is, fit check, hero `three-tabs.svg`, guide TOC) + `docs/README.md` (chapter map, 6-row "Other tools" table linking shelf pages, reference shelf; kept for `docs/reference-index.md` L6).
  - **Setup by frequency (3 step-by-step pages, matching `04`-`08` depth):**
    - `01-install-akrogon.md` (once per machine): check prerequisites incl. `agy`, write a complete copy-pasteable `~/.akrogon/config.yaml` (full harness/model/effort/flags, no `<other flags>` placeholders), run `bun src/akrogon.ts install`, add `PATH`, verify `akrogon config`, and why one install serves many repos (`acme-core` + two product repos).
    - `02-set-up-a-repo.md` (once per project): worked `/init-akrogon` walkthrough on `client-portal` (same example app as `04`-`08`), what `akrogon init` writes, key `issues/config.yaml` settings, grounding (`docs/reference-index.md` + `AREA.md`), and how to verify setup (`akrogon config`, `akrogon status`).
    - `03-your-three-tabs.md` (daily workspace): create the herdr space named after the repo (`src/hc.ts`), open `t-`, `c-`, `w-`, and verify readiness for charting (`04-a-charting-session.md` L7-15 shrinks to a short back-link).
  - **Charting (5 approved pages, numbers unchanged):** `docs/guide/04-a-charting-session.md` to `08-hand-off.md`.
  - **Run & Merge (1 page):** `09-build-and-merge.md` (`akrogon next`, slot A/B, automatic merge turn, red-to-repair, completion/Discord, what starts sessions).
  - **Watch & Recovery (2 pages):** `10-while-you-are-away.md` (watcher in `w-`, keeping `tests/watch-timer.test.ts` L1370-1403) and `11-when-work-stops.md` (`failed`, park/pause/stop).
  - **Removed:** `01-what-akrogon-is.md`, `10-merging.md`, `13-other-tools.md` (sync/seed/lessons already live in `docs/reference/commands.md` + `skills.md`; hand-written issues fits in `docs/reference/files.md`), `docs/reference/roll-back-a-release.md` (fold into `docs/reference/releases-and-updates.md#rollback`, update `tests/rollback.test.ts` L140), and `docs/reference/limits.md` (29 lines, fold into `README.md`/guide). Cuts ~10-12 low-value SVGs while giving install/setup real room.
