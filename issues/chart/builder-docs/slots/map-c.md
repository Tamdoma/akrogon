## Practitioner questions a docs lead would ask
1. Does the opening screen shift the reader's mental model in 60 seconds (why charting contracts + two seats + merge queue stops fragile AI workflow babysitting) with zero marketing fluff?
2. Can an operator pick **Charting mode** and **Build route** in under 30 seconds for a real job (fast small feature vs complex multi-part build) and immediately know why autopilot uses `Lifecycle`?
3. Are `t-<repo>`, `c-<repo>`, and `w-<repo>` concrete — what you type in each, what runs overnight, and what always waits for you (keys, approvals, failed leaves)?
4. Does Ch 1 make one-Akrogon-to-many-repos crystal clear using a believable made-up upstream repo + product repos?
5. Is every unavoidable technical term (`worktree`, `grounding`, `systemd`) explained in one plain sentence or moved to `docs/reference/`?

## Lifetime pitfalls
- **Auto-dispatch bypassing signposts 7a:** Unparked issues using `blocked-by` alone auto-launch via `akrogon next --wake` as soon as Ch 2 merges; park downstream issues until operator sign-off.
- **Broken links and pinned tests:** Removing `docs/README.md` or `docs/reference/where-things-go.md` breaks out-of-scope `docs/reference-index.md` in `tests/docs-links.test.ts`; moving `watch-while-away.md`, `roll-back-a-release.md`, or `watch-loop.svg` breaks `tests/watch-timer.test.ts` and `tests/rollback.test.ts` unless updated in the same leaf; forward links to unwritten SVGs fail `tests/docs-links.test.ts`.
- **Skill release lag & handover breakage:** Per `skills/chart-issues/SKILL.md` (`## Handoff`), skill renames reach live doors only after the next deployed release (`~/.akrogon/current`); changing `## Mode record` tokens without legacy fallback breaks in-flight handovers.
- **Over-broad `manual` rename or stale residual terms:** Naive replace breaks unrelated `"manual next"`/`"manual prompt"`/`"manual rollback"` code and tests; leaving `"quick fix"` or `"attended"` in `docs/reference/words.md`, `skills.md`, or SVG labels reintroduces drift (`learnings/LESSONS.md`, `ambiguous-prose-after-rename`).
- **GitHub SVG failures:** GitHub's `<img>` CSP blocks external Google Fonts (use system font stacks so boxes never overflow); transparent `#0f0f0f` line-art vanishes on GitHub dark mode (use opaque `#f4f1e6` cards); `watch-loop.svg` must never contain `cron`, `expir`, or `akrogon status` (`tests/watch-timer.test.ts`).
- **Dual-home doc rot:** Copying full CLI flags or config schemas into Ch 1–5 causes silent drift when code changes update only `docs/reference/`; keep exact syntax exclusively in `docs/reference/`.
