- R1. A release or rollback can run mismatched text and scripts. Preserve the legacy reader's prefix on the new release. - R3. A partial inventory or a word in a leaf row can look like a verdict. Read the command's exit and the complete output, use the exact final control line, and distinguish empty success from unreadable inventory and core refusal.
