# Leaf review, slot B

Four disagreements:

1. **Ambiguous `"eligible slug= row"` for stand-ins risks hanging `watch standin cell` (`design.md`, sections `Taken` Q4 and `Leaf architecture`).**
   - *Fact & evidence:* `design.md` instructs `tests/fixtures/watch-hook.sh` and `tests/fixtures/watch-agent.sh` to act only on exit 0, `paused=false`, and `"at least one eligible slug= row"`. In `tests/e2e/watch-live.e2e.ts` (`watch standin cell`, `shape === 'root'`), only one leaf (`watch-live-leaf`, slot A = `fake --model idle`) is staged. Before `pause`/`unpause`, the watcher already runs `akrogon next --all` on start, second start, due 1, due 2, and the coalesced due; in `src/next.ts` (`dispatchSlot`), three silent stops of `fake --model idle` move `watch-live-leaf` to `phase=failed`. After `unpause`, `watch standin cell` asserts `checkTurn(..., 'acting', ...)` and `waitCallAtTurn(callLog, 'next', ...)`.
   - *Consequence if built as written:* If the implementer interprets `"eligible"` as excluding `phase=failed`, `watch standin cell` (`shape === 'root'`) hangs at the post-unpause `acting`/`next` wait. Either specify `"any slug= row"` (non-empty inventory, which still proves empty-then-staged) or require `watch standin cell` (`shape === 'root'`) to stage a fresh waiting leaf before `unpause`.

2. **`design.md` (`Leaf architecture`, `Open for the plan`) contradicts `readiness.yaml` (`proofs[0].limits`) on verifying `OBSERVE_AKROGON` propagation in `pi`.**
   - *Fact & evidence:* `design.md` states `"The plan confirms the pi harness passes OBSERVE_AKROGON from the watcher env into its tool subprocesses (a free preflight-level read is enough)"`. `tests/e2e/watch-live.e2e.ts` (`watch preflight: the leaf skill is the only watch-issues the harness sees`) sends no prompt and runs no tool subprocess, which `readiness.yaml` (`proofs[0].limits`) itself records: `"no paid model turn; does not prove OBSERVE_AKROGON reaches pi's tool subprocesses"`.
   - *Consequence if built as written:* Following `design.md`, the planner cannot confirm `OBSERVE_AKROGON` tool propagation with `watch-preflight` and risks discovering a stripped env var only during the paid run. Either drop the preflight claim (rely on `tests/e2e/watch-consults-body.ts` `body` precedent where `pi` passes `AKROGON_HOME` to `consults.ts`, or use `/proc/$PPID/cmdline` in `logbin/akrogon`).

3. **`readiness.yaml` (`grants[0].stop_line` and `fixtures`) contradicts `tests/e2e/watch-tier.ts` (`sessionPaths`, `startWatchTier`, `stopWatchTier`).**
   - *Fact & evidence:* `readiness.yaml` sets `fixtures: []` and `stop_line: "no other harness account, provider or outside write; no write outside the tier root and the leaf's implementation folder"`. `tests/e2e/watch-tier.ts` (`sessionPaths`, `startWatchTier`) writes outside both `AKROGON_E2E_ROOT` and `<leaf>/implementation/`: `$XDG_RUNTIME_DIR/akr-e2e-watch*` (`coreRuntime`, `lock`) and `~/.local/state/herdr-core/akr-e2e-watch` (`coreState`), cleaned and absence-checked by `stopWatchTier` (`absent(session)`), plus `pi`'s own session transcript under `~/.pi/`.
   - *Consequence if built as written:* An implementing or reviewing seat enforcing `stop_line` literally is blocked from executing the paid `pi` cell required by `brief.md` Criterion 6. Record the throwaway `akr-e2e-watch` core runtime/state fixture (and `pi` session transcript) in `grants[0]` / `stop_line`.

4. **Non-existent watcher env listed as open for the plan (`design.md`, section `Leaf architecture`, `Consumers of changed state`).**

   - *Consequence if built as written:* Wastes a planning check on a watcher env that does not exist; remove the open item.
