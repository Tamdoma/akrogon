# Territory map B

## Cause and reach

- F1. Confirmed mechanism, unproven historical trigger. `panes()` runs unqualified `herdr pane list` (`src/shell.ts:202-215`), inheriting the caller's environment (`src/shell.ts:93-103`). Host reconcile caches that single list (`src/reconcile.ts:1153-1160`), maps slices across every supplied repo (`src/reconcile.ts:1173-1175`), then judges each recorded tab against it (`src/reconcile.ts:1191-1199`). `tabLive` compares only tab ids (`src/reconcile.ts:255-257`). An absent foreign-session tab therefore permits `systemctl stop`, with only a fresh live-run check under the admission lock (`src/reconcile.ts:203-218`). A busy matched slice has no process veto. The reported lingua-relay trigger and G18 kill remain timing-based, not proven by this inspection (`issues/chart/host-reconcile-session/INTAKE.md:13-20`).
- F2. Exactly two production call sites: `reconcileRepos` calls host reconcile after its selected repo loop, passing **all registered repos**, even if the repo loop skipped paused repos (`src/next.ts:1307-1322`), and the `tab_closed` branch calls it directly (`src/next.ts:1429-1447`). Paths through `reconcileRepos`: explicit target or manual cwd selection (`src/next.ts:1357-1360,1383-1399`), `next --all` both outside and inside a registered repo (`src/next.ts:1400-1410`), `next --resume` (`src/next.ts:1412-1428`), and `unpausePass` (`src/next.ts:1512-1526`, CLI `src/akrogon.ts:143-147`). `start` also reaches the target path through `nextCommand(leaf.path)` (`src/stop.ts:97-106`). CLI `next` enters at `src/akrogon.ts:105-110`. Other pane hooks dispatch and may close a merged tab, but do not call host reconcile in that branch (`src/next.ts:1463-1497`).
- F3. Other host-wide judgments: `dropPath` uses the same list for cwd vetoes before deleting retired temp, unregistered stores, temp strays, dead-pid temporary files, `runs/last-start`, and retired locks (`src/reconcile.ts:1250-1287,1290-1352`). Contrary to the comment at `src/reconcile.ts:1248-1249`, dead-pid temporary files also call `dropPath` and need pane availability (`src/reconcile.ts:1322-1324,1333-1339`). Host slice broadcast protection also compares an unqualified pane B id (`src/reconcile.ts:183-205,1194`). Outside host cleanup, global capacity counts every registered repo against one session's panes (`src/next.ts:353-366`). `paneOwners` similarly attributes one list across repos (`src/next.ts:1325-1334`). Per-repo cleanup shares the slice-stop rule and invoking inventory, so fixing host alone leaves that path exposed (`src/next.ts:1311-1315`, `src/reconcile.ts:508-525`).

## Material forks

- O1. **Delivery:** an interim change can conservatively retain unprovable slices, reducing immediate kills, but delays leftover cleanup and must cover both slice-stop paths. Folding into session-routing uses its resolved-session inventory and avoids duplicate discovery, but waits for that delivery. The emitted routing design already explicitly includes host refusal containment and scoped liveness (`issues/open/herdr-session/session-routing/design.md:14-17,30-32,71-75`). Recommendation: use that interface for the durable fix. Any expedited guard needs a concrete removal condition, and changing emitted scope requires new intake, not edits (`issues/chart/host-reconcile-session/INTAKE.md:5`).
- O2. **“Cannot be judged”:** absence from the invoking session proves nothing about another session (F1). Absence of the raw id from every readable running session avoids false absence but lets same-id unrelated tabs retain garbage. Resolve the repo, test its tab id only there, and use all-session cwd matches as separate vetoes. If a potentially relevant running session is unreadable, retain what it might hold. Blocking all cleanup for any unreadable session is simpler but can let one broken session prevent unrelated cleanup indefinitely. The emitted contract already chooses resolved-session tab identity and all-session cwd/unknown vetoes (`issues/open/herdr-session/session-reads/brief.md:14`, routing design `:30-32`). Keep stopped/server_not_running distinct from unreadable (`issues/open/herdr-session/session-routing/brief.md:15`).
- O3. **Busy slice without a visible tab:** retain it until its processes exit, or stop it after trustworthy tab absence is established. Retaining every busy slice protects detached work but leaves runaway descendants alive indefinitely. Stopping preserves intentional leftover cleanup but can kill detached work. Today stopping is deliberate for matched unfinished and finished leaves, while unmatched busy slices are retained (`tests/release-any-phase.test.ts:190-207,421-425`, `tests/leaf-slices.test.ts:323,446-479`). Recommendation: preserve that policy after correct session judgment unless the operator explicitly changes it. “Live process” alone does not currently mean “live seat.”
- O4. **Leftover cleanup:** with trustworthy tab absence, keep the existing matched-slice stop, own-slice/run/broadcast vetoes and admission-lock recheck (`src/reconcile.ts:203-218`). If O3 instead chooses process retention, empty slices still clean automatically, but busy leftovers need an explicit stop or process exit. Unmatched slices already require readable leaf ownership, no live run and an empty readable cgroup (`src/reconcile.ts:1203-1232,155-180`). Disabling the host step entirely also loses failed-unit reset and host filesystem cleanup (`src/reconcile.ts:1235-1250`).

## Regression proofs and pitfalls

- A1. Extend the existing two-repo host isolation case to two sessions: invoke repo Y while X holds a busy matched slice and a live tab, and assert no stop plus retained temp. Repeat through per-repo cleanup, `--resume`, `unpause`, and `tab_closed` (F2). Current coverage places the other repo's tab in the same fake database (`tests/leaf-slices.test.ts:28-57`). Include merged/failed and unfinished leaves because both intentionally reach stops (O3).
- A2. Reuse identical tab and pane ids across sessions. A foreign same-id tab must not keep a dead local tab, and an unrelated pane B must not decide broadcast liveness (F1/F3). Cover a live cwd outside the resolved session, an unreadable running session, a stopped session, and failed discovery. Assert filesystem preservation as well as absence of slice stops (F3/O2).
- A3. Prove cleanup still works when all relevant reads succeed and tabs are gone, while own slices, live admission records, unreadable leaf records and occupied unmatched slices survive. Reuse existing tests rather than replacing the stop policy accidentally (`tests/leaf-slices.test.ts:66,108,415,446,485`; `tests/release-any-phase.test.ts:192,379`). Include a launch/close within one pass so cached inventory cannot produce a stale stop (`issues/open/herdr-session/session-reads/brief.md:15`).
- A4. Fake support: session discovery, `--session`, isolated inventories with colliding ids, and per-session unreadable/server_not_running responses and call records. Today the fake has one `FAKE_HERDR` database and raw argv dispatch (`tests/fake-herdr.ts:56-85,153-162`). Session-routing already owns the multi-session extension and defaults, so consume it rather than invent another fake (`issues/open/herdr-session/session-routing/design.md:67,76`). Existing fake systemctl/cgroup fixtures supply busy/empty slice and stop evidence (`tests/release-any-phase.test.ts:398-425`).

## Existing coverage and exact gap

- F4. Routing criterion 6 already requires resolved-session `tabLive`; its design names host reconcile refusal containment. Reads criterion 2 already requires all-session cwd protection and no closing under relevant uncertainty, and criterion 3 requires refreshed inventory (`issues/open/herdr-session/session-routing/brief.md:18`, design `:31,75`; `issues/open/herdr-session/session-reads/brief.md:14-15`). This is substantial overlap, not a wholly unspecified mechanism.
- F5. Neither brief explicitly proves **systemd slice-stop safety when another repo invokes the host pass**, distinguishes a busy matched slice from a busy unmatched slice, or enumerates host `dropPath` deletion vetoes (`issues/open/herdr-session/session-routing/brief.md:13-20`; `issues/open/herdr-session/session-reads/brief.md:13-19`; F1/F3/O3). The new intake should make those outcomes and the process policy explicit, with A1-A4 as proof obligations, without silently rewriting the emitted contracts.
