The holder runs those same commands after the command has finished stacking the batch, and again whenever integration requires fresh checks. This wins because running a check also performs its prerequisite. **Reused:** existing command strings, package manager, cache, seat-run checks and existing failure handling. **New:** preparation prefixes in repository configuration and a skill instruction to prepare before direct proofs that bypass those commands.
