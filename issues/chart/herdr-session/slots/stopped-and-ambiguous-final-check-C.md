# Final-shape check, seat C: stopped-and-ambiguous

Defects and missing pieces only, checked against `src/shell.ts` at c5cf7be7, 2026-10-24.

- D1. Q3's deadline does not reach the calls it names as written. The deadline parameter exists on `run` (`src/shell.ts:93-114`: a `Promise.race` timer that kills the child and rejects) and on `retryCommand` (`src/shell.ts:130-134`). But every discovery call named in Q3 goes through `herdr()` (`src/shell.ts:202`), which calls `command()`, and `command()` hardcodes the deadline to `undefined` (`src/shell.ts:124-126`). There is no way to pass a deadline to a `workspace list` or pane/tab list today without adding a parameter through `command()` and `herdr()` (or bypassing them). The record should name that plumbing instead of implying the existing parameter covers these calls unchanged.

- D2. A deadline hit is not recognizable as one by the code that must classify it. `run` rejects with a plain `CommandError` carrying code 1 and stderr text `deadline <ms>ms exceeded` (`src/shell.ts:114`). `herdrError` maps any non-JSON stderr to code `exit 1` (`src/shell.ts:188-197`), indistinguishable from herdr itself exiting 1 with unstructured stderr. "A deadline hit counts as an unreadable session" therefore needs a stated recognition rule (match that stderr text, or a typed marker) or deadline hits and ordinary herdr failures land in the same bucket by accident rather than by record. Note the deadline reject also bypasses `retryCommand`'s retry branch, which only retries returned non-zero results (`src/shell.ts:131-134`), so the 10-second bound holds for a hang either way.

- D3. `session list --json` cannot ride the same wrapper as the other discovery calls. Its live output is `{"sessions":[...]}` (probe, 2026-10-24), while `herdr()` parses a `{result: ...}` envelope (`src/shell.ts:202-212`), and the call must also stay unpinned by `--session`. Q3 groups it with the per-session lists under one mechanism; as recorded, an implementer must still invent its separate call and parse path (through `run`/`command` directly, which is also where D1's deadline plumbing differs).
