2. **Missing interface constraint on `routing.merge.slots` (`design.md:66`)**: `design.md:66` leaves `"whether the merge route keeps a seat or skill at all"` open for the plan, but `failureSchema` (`src/state.ts:15`) requires `slot: slotSchema` (`'A' | 'B'`), and `src/phase.ts:180` (`refuseEnclosingCompletion`) and `:431` read `requiredSlots(phase, fix_rounds)[0]`. Setting `routing.merge.slots = []` crashes `merge -> failed` (criterion 3 push error and `refuseEnclosingCompletion`) with a Zod error unless `failureSchema.slot` becomes optional/nullable; keeping `slots: ['B']` makes `src/status.ts:629` report `waits_on: ['B']` for waiting merge leaves. **Fix**: name `failureSchema` (`src/state.ts:15`), `src/phase.ts:180,431`, and `src/status.ts:629` in `design.md` consumers/interfaces so the plan settles both together.
3. **Missing owned skill/doc surfaces**: `skills/implement-issue/SKILL.md:42` explicitly references `"under the merge-issue solo rule"` for rebase conflict resolution, which becomes a dangling pointer once solo rebase moves to `check-issue` `## check.repair`; `src/AREA.md:15` also documents `wake=` seat handoffs. **Fix**: add `skills/implement-issue/SKILL.md` (and `src/AREA.md`) to owned surfaces.
4. **Criterion 1 wording (`brief.md:13`)**: `"the next queued leaf's land run starts in the same akrogon next pass"` — a red verify runs inside `akrogon land` (`src/land.ts`), which starts the next holder via `mergeWake` rather than inside `akrogon next`. **Fix**: say `"starts in the wake after the exit"` (keeping `"in the same akrogon next pass"` for criterion 2's conflict/dirty-worktree exits in `mergeTurn`).
5. **Criterion 8 audit nit (`brief.md:20`)**: `"existing skill-text tests in bun test stay green"` approaches `shapes.md`'s ban on claiming repo health outside own proof; criterion 8 already proves the text via `"the reviewing seat reads the named sections against forks/red-exit.md Taken 3"` (and `checks.test` runs at review/merge anyway). **Fix**: drop the `"existing skill-text tests in bun test stay green"` tail.
