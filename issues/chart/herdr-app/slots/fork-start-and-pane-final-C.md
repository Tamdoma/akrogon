# start-and-pane final check, C (2026-11-06)

Objections to mechanism only, picks untouched.

1. Q2b cannot name the tab when no window runs. The tab entry (`id`, `name`, `root` tree with pane ids and weights, live `doc.get` today) is written by herdr-app when it adopts the labelled terminal (AGENTS.md "The model": an unknown id becomes a new tab). With the window closed nothing adopts, so the document has no tab to rename and "touching only that tab's name" has no target; a window started later adopts the tab under Herdr's place name. Writing the whole entry from akrogon invents the document shape. Smallest fix inside 2d: the start command renames when the tab entry exists, else records the pending name and the listener (or the next start/`next` pass) renames once the entry appears; the "window opened later" probe must check the slug name, not only visibility.
2. `doc.set` is a whole-value write ("Any JSON value", `hc schema`), and AGENTS.md says the newest accepted document wins with no merging. So akrogon must write back everything it read: the identity Taken strict schema may not strip unknown fields on this path (passthrough parse), or a rename erases fields akrogon does not model. Done-criterion: a rename leaves the rest of the document byte-equal apart from the name.
3. Probe gap: herdr-app writes the document again when it adopts seat B (new pane under the same root). The "running window does not overwrite" probe must run as rename A, then start B, then re-read; and once more after a structural command (`pane.split`), since a rewrite from herdr-app's in-memory model is the case that loses the name.
4. Q1 vs identity Q1: every hc call strips `HC_TERMINAL_ID`, and `hc run` defaults the parent to that terminal (`hc run --help`). Consultants get `--parent <door>` only if the start command reads the caller's id before stripping and passes it explicitly. Record that as a design part.
5. engine-shape Q1 lists the hc module's closed commands (prompt, status, close tab, kill). Start and `doc.get`/`doc.set` are additions to that list; record them there so the two Taken do not disagree.
