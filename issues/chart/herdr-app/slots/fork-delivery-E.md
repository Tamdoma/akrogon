# Fork Notes: `delivery` (Seat E)

## Q1. First task at start (`hc` templates vs direct `hc run <argv> "<task>"`)

1. **Pick:** **Direct `hc run --bg ... <argv> "<task>"`**, proven during the start helper's post-spawn check by `hc get --json <address>` showing `state === "live"` and (`status?.state === "working"` or `turn >= 1`), failing fast on `state === "finished"` or `status?.state === "blocked" | "error"`.
   - **Reason:** Passing `"<task>"` in `argv` avoids pasting the initial prompt into an unsettled TUI (worked 9/9 in operator tests and 4/4 across `claude`, `codex`, `pi`, `agy` in live charting), preserves per-seat `{model}` and `{effort}` interpolation from [`seats()`](file:///home/ivan/Work/infra/akrogon/src/config.ts#L170-L197), and honors [`INTAKE.md`](file:///home/ivan/Work/infra/akrogon/issues/chart/herdr-app/INTAKE.md#L75) ("not hardcoded in an hc template"). Checking `working || turn >= 1` covers both active turns and fast turns that already finished while catching startup popups (`reported: false`, `status: null`, `turn: 0`).
   - **Cost:** Direct runs leave `first_message: null` (`hc schema`), so the start helper polls `hc get --json <address>` during its placement/readiness window (~10–15 s) instead of reading `first_message.sent`.
2. **Rejected options:**
   - **`hc` template runs (`~/.config/herdr-core/templates/<kind>.md`):** Rejected. `herdr_core::templates::TemplateInfo` (`hc` binary strings) binds a static `command` in frontmatter with no `{model}`/`{effort}` placeholders per repo/leaf/seat ([`src/config.ts`](file:///home/ivan/Work/infra/akrogon/src/config.ts#L170-L197)), mutates user-global `~/.config/herdr-core/templates/`, and delivers the task by waiting for output settle then pasting into the TUI—which is vulnerable to startup dialogs and paste absorption.

4. **Pitfalls & removals:**
   - *Startup dialog (`codex` Daybreak popup or trust prompt) holds `status: null, turn: 0`:* Removed by **design part** + **leaf done-criterion**: start helper requires `status?.state === "working" || turn >= 1` within its readiness budget; on timeout it reads the screen (`hc read --lines 0`), kills the unready agent (`start-and-pane` Q4), and exits non-zero.
   - *Window closed at leaf start:* Removed by **design part**: `hc get --json <address>` talks to `herdr-core`, so `working || turn >= 1` works even when `herdr-app` is closed (`start-and-pane` Q2/Q2b N2).

## Q3. Silent stop (catching, recovery, and prevention)

1. **Pick:**
   - **Leaf seats (engine + watcher):** The listener's automatic `next` pass enforces one automatic prompt per `(address, phase)` (`state.prompted[slot]?.address === current.address` returns early), so a turn ending without `akrogon phase` leaves the seat `done`/`idle` with `current.turn > state.prompted[slot].turn` and `slot` not in `state.done`. [`observe.ts`](file:///home/ivan/Work/infra/akrogon/skills/watch-issues/SKILL.md#L30-L40) surfaces this state (`idle`/`done` while unfinished); `watch-issues` reads `hc read <seat> --lines 80` (distinguishing a Pi question or blocker from a silent stop) and recovers by running explicit `akrogon next <slug>` (which allows re-prompting an idle/done seat once per recovery cycle, bounded by the existing 2-cycle recovery cap in [`skills/watch-issues/SKILL.md:43`](file:///home/ivan/Work/infra/akrogon/skills/watch-issues/SKILL.md#L43)).
   - **Consultants (chart door):** `hc wait --children all` is treated strictly as a wakeup net, never completion proof ([`INTAKE.md:200`](file:///home/ivan/Work/infra/akrogon/issues/chart/herdr-app/INTAKE.md#L200)). Completion of seat `<L>` requires **both** the `<hc>done <L>: <path></hc>` report and a non-empty file at `<path>`. When `hc wait` returns with seat `<L>` `done`/`idle` and `<path>` missing, the door runs `hc read --lines 40 <seat>`, sends **one** nudge via `hc send <seat>` naming the missing return file and brief path (as `t15` did for `ak-slot-e`), and if the next turn still produces no file, kills and restarts `<seat>` (`hc kill` + start command).
   - **Prevention:** Enforce in skill briefs that agents never pass unverified `StartLine` offsets on unread files (the exact trigger of `ak-slot-e`'s turn 12 stop: `StartLine: 150` on 56-line `forks/start-and-pane.md` returned 1 line, causing `agy` to end its turn after one tool call) and must end their turn only after `write_file` + `hc send`.
   - **Cost:** A leaf seat that silently stops waits until the next watcher fire (up to 20 min) unless the operator runs `akrogon next <slug>`.
2. **Rejected options:**
   - **Automatic listener re-prompt on every turn-end without `phase`:** Rejected. Violates `engine-shape` Taken ("status is a wake, never success evidence ... one prompt per seat per phase") and breaks on Pi, which prints questions and ends its turn as `done` ([`INTAKE.md:154`](file:///home/ivan/Work/infra/akrogon/issues/chart/herdr-app/INTAKE.md#L154)).
   - **Immediate kill-and-restart on first consultant silent stop:** Rejected; a one-line `hc send` nudge recovered `ak-slot-e` in seconds while preserving warm context.
