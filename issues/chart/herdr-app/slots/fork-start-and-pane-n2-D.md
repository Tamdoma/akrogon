# N2 check: slot D

One objection. As written, the window-closed sweep "renames any leaf tab of a recorded leaf whose name is not its slug" also renames failed leaves' tabs back to the slug. Today `phase` deliberately renames a failed leaf's tab to `<slug> failed` (`src/phase.ts:125-127`) and back to the slug only on recovery out of failed (`src/phase.ts:230-231`), and that rename ports to `tab.rename` on the new substrate. The sweep would silently undo the failure marking on the next pass that finds the window open. The mechanism works if the sweep's expected name is derived from the leaf's phase (`<slug> failed` when failed, slug otherwise), or if it only touches tabs whose name is still empty; the recorded probes should include a failed leaf whose window opens after the failure rename.
