- Pick: one strict fake `hc` binary replacing `fake-herdr.ts`, same pattern as today (a bun script on PATH driven by a per-test state file, bundled per worker by `tests/isolation.ts`), answering only the hc commands the engine's hc module calls (`run`, `send`, `get`, `ls`, `label`, `kill`, `events` replay, `connect` `doc.get`) with JSON shaped by the same strict schemas the module parses (identity Taken's `hc schema` boundary), and refusing any unplanned call with a clear error. A small fake `herdr-app` answers `ls` and `tab.rename` only. Reason: closest to today (one fake binary, same isolation preload, the 31 users keep their structure), fast enough for the concurrent 30 s suite, and the schemas are shared so the fake cannot drift from what the module accepts. Cost: the fake can still disagree with real hc on behavior; Q2's real runs cover that.

Real hc core for most tests (a core per worker under `--parallel=4`, startup cost per file, and agent status needs a real harness; slow and flaky inside a 30 s budget).

## Q2 real e2e
- Pick: a separate e2e command, not in the normal `test` check, run by the leaf that changes a covered behavior and once in full before old herdr is deleted (signpost 2a's proof). It starts a throwaway core (`HC_SESSION=akr-e2e-<id>`, scratch XDG paths, its own herdr-app home with herdr-setup linked), runs real flows and stops only that core. Free parts use a stand-in program (a shell script that reads its task and runs `hc send` back): start with first task, report, listener on `hc events`, kill and restart, labels, tab naming and weights with a window, notices, containment scope. Agent-specific parts (status turns, silent stop, reset, skill discovery) use one real smallest run per kind within the 7a budget. Reason: the operator's "nothing should break" needs real hc, and the normal suite must stay fast and free. Cost: a second command and a paid budget per full run.
- Pitfall: hc reports status only for recognized agents, so a stand-in cannot prove turn-based delivery. Removed by: those cases stay in the real-agent part; probe what status a stand-in gets.
