# tests rebuttal — slot C, 2026-11-07

Attributions to me are correct. Two disagreements.

1. Q1, the strict fake `hc` "needed for error and race injection a real core cannot produce on cue". Each named case is producible on the real fixture core, on cue: `name_taken` by a second `hc run --name` with the same name; a seat blocked on cue by the stand-in emitting `state=blocked:kind=permission` (E's probe got exactly that); `started: false` by a 7501 stand-in that stays `idle` and ignores the line; a lost stream and `stopped_by_restart` by `hc server restart` on the fixture core; an unreadable session by `chmod 000` on its socket; a stopped session by stopping the fixture core and removing nothing else, which is also how identity Q1 sees it (no socket file in the runtime dir). The trap the corrections record cuts the other way: since any hc command starts a new core after a stop, hc never answers "server not running"; a fake that scripts such a reply, as today's `fake-herdr.ts` `serverDead()` does for `server_not_running` (`src/shell.ts:329`), tests a vocabulary the real hc does not have, and B's "capture from real hc" cannot capture a reply hc never gives. Only the window is unreachable in tests, so only `herdr-app` earns a fake. A fake `hc` beside a real core is two sources of truth for one contract; the second drifts per release and never fails loudly.

2. Q2, A/B/D's move of the free real-hc tests out of the `test` check "to keep the suite deterministic in verify sandboxes". The suite already runs real systemd units (`tests/run-units.test.ts`, `leaf-slices`) and real git repositories inside those sandboxes; a 13 ms core with a scratch runtime dir is no less deterministic than a transient scope. Outside `test`, `full: [test]` never sees an hc regression at merge, which is the moment the 2026-11-06 direction ("nothing should break") needs it. A sandbox without hc fails the check clearly, as one without systemd would. Keep them in `test`, serial per fixture where they share a core.

No disagreement with D and B's additions to the 2a proof (one real leaf through its whole life, one consultant round, one watcher check, logs kept).
