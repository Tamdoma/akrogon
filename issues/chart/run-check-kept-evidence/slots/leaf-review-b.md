## Disagreements

- D1. Marker placement is underspecified and one reading breaks criterion 1. design.md "Literal interface" says the marker is written "after the child exits and before the `finally`". In `checkedRun` the late `ownerRefusal(target, repo, true)` check runs after the child exits and calls `refusePublish(refusedReason, result)`. A marker written right after `spawnLogged` returns leaves a red, late-refused root holding both `refusal.json` and `.akrogon-kept`, which criterion 1 forbids ("no `.akrogon-kept` as today"). It also keeps the root when `writeFileSync(kept, ...)` or `appendTiming` throws after a red exit, against "a thrown error behaves as today". Fix in the design: the keep is decided at the successful return of the inner block, after the late refusal check and the `check_end` row. This also answers "Open for the plan": a second local set at that return, read by the `finally`.
- D2. New failure the draft does not name: the child removed its own TMPDIR and exited nonzero (`rm -rf "$TMPDIR"; exit 1`). Today `rmSync(runRoot, { recursive: true, force: true })` in `checkedRun`'s `finally` succeeds on a missing path. As drafted, the marker write throws ENOENT, so run-check ends with an exception in place of the child's exit code and the `check <name>:` line, and `verify` loses the member's result. This differs from C's chmod guard, which the fork rejected because `rmSync` has the same exposure; a missing root has no exposure today. Fix: add a done-criterion "a red command that deleted its `$TMPDIR` still returns its exit code and leaves no run root", and state in the interface that the marker is written only when the run root still exists.
- D3. Small accuracy point, no behavior change: `self-update` never holds a marked root. `checkedRun` is called only from `runCheck` and three `src/verify.ts` sites; `src/self-update.ts` uses `leafTemp(repo, 'self-update')` as scratch without it. design.md Taken 4, Exclusions and "State changes" name `self-update` beside `checkout`. Consequence if built as drafted: the implementer may write a `self-update` test or doc clause for a state that cannot occur. This is Taken text, so note it in the leaf's Exclusions instead of editing the fork.

- Binding decisions: each has a home or an exclusion. Nothing contradicts `## Taken`.
