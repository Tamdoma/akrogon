Disagreements:

- D2 budget-rules criterion 3 names test files and prescribes a test's code. Fix: "Proof: own tests in the `test` check", and move "docs-links reads the link set from the skills folder" to the design, which already says it.
- D3 budget-rules criterion 4 would refuse a free cell. tests/e2e/watch-live.e2e.ts has three modes, and its header marks `AKROGON_E2E=watch-preflight` with a real kind as "Free, no prompt sent". The criterion says "watch-live.e2e.ts for claude, codex, pi and agy". Also wrong for the others: watch-stop.e2e.ts accepts only codex or agy, and kinds.e2e.ts runs every kind in one run. Fix: "the paid cells: kinds, watch-stop, watch-consults, and `watch-live` with a real kind; `watch-preflight`, the `standin` cell, window and notices start without it".
- D4 budget-rules criterion 4, "the sessions the run plans" has no value for watch-consults. Its header counts "the watcher, initial consultant and each replacement that receives a task", and the watcher model starts the replacements, so the test cannot cap them at start. Fix: watch-consults refuses below 2 and reports the sessions it counted, and the review reads that count against the ledger row. A count above n does not fail a green run.
- D5 Item 6's minutes have no home. session-ceiling exports `AKROGON_SESSION_MINUTES` and no budget-rules criterion consumes it. tests/e2e/watch-consults.e2e.ts hardcodes `Date.now() + 14 * 60_000` in its test body. Fix: add to criterion 4 "a paid entry point with its own session deadline takes it from `AKROGON_SESSION_MINUTES` and reports it". The alternative is to drop the export from session-ceiling and state the exclusion.
- D6 session-ceiling criterion 5 cannot show its deliberate break. Two real processes rarely collide, so the test stays green with the lock removed, and the design requires each criterion to go red on one break. Fix: "while another process holds `<globalHome>/budget.lock`, a `--sessions` run writes no row and starts no command, and it proceeds after release". tests/run-permit.test.ts already proves waits this way.
- D7 session-ceiling criterion 2, "when the next session frees" is unclear for n above 1 and undefined when n exceeds `sessions_per_day`. Fix: "prints the window total, the ceiling and the time at which this n fits, or that n exceeds the ceiling and never fits".

With the fifth symlink the door reads that file, and chart-issues names neither. Correction 4' gives the stop (the Needs wait) but not the file.
