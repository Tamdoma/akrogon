# Control notes, slot A (written before reading control-B)
Q1 pick: machine-local file `<globalHome>/paused.yaml` (gitignored like `.lock`, .gitignore:5) mapping registered repo key -> {since}. Set and cleared by `akrogon pause <repo>` / `akrogon unpause <repo>`, taking a registered repo key (refuse unknown key), working from any cwd. Under the global lock. Second pause or unpause of the same repo refuses with a clear message (no silent no-op).
Rejected: key in repo issues/config.yaml (tracked, needs a main commit, spreads to every checkout and `akrogon sync`); key in machine config.yaml (gitignored but hand-edited, a command rewrite drops comments; src/config.ts:29 parses it strictly); cwd-based repo like park (src/park.ts:50 requireRepo(cwd)) because hooks and the operator often sit in another repo's pane and the plugin cwd lesson (learnings 2026-09-28) shows cwd surprises.
Q2 pick: unpause runs one pass for that repo, the same one startup `--resume` runs (allocated or merged leaves, cleanup, merge pass; src/next.ts:1270-1282), scoped to that repo. Reason: with Boundary 1a nothing automatic happened while paused, and after closing seats no pane exists to fire an event, so permit-only would leave leaves stranded until a manual next. Cost: unpause launches seats immediately. Rejected: permit-only (stranded leaves), full `--all` sweep (starts never-started leaves the operator did not ask for).
Q3 pick: `akrogon status` prints `paused since <time>` beside the repo heading (src/status.ts:379); a skipped automatic pass prints nothing and exits 0.
Evidence: better-than-training, Temporal CLI `schedule toggle --pause|--unpause --reason` (docs.temporal.io/cli/schedule, read 2026-10-08): separate pause state, shown in describe/list. Kubernetes `kubectl cordon/uncordon` (primary docs): paired verbs on a named target. Practitioner search: none found for per-project agent dispatch.
Pitfalls: paused.yaml missing = nothing paused (normal state, not an error); a pause naming a repo later unregistered stays inert, status shows it; unpause pass must re-read pause under lock.
