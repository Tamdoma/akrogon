# Leaf draft review — Slot B

1. Invocation classification needs explicit precedence. Design says automatic is any run carrying HERDR_PLUGIN_EVENT_JSON, but the brief promises manual targets and --all run in full. Current `src/next.ts:1232` deliberately ignores event JSON when an input is supplied, so a typed target/--all with inherited event JSON stays manual. Exact fix: specify `--resume` is always automatic; other explicit inputs (target/path/--all) are manual and ignore inherited event JSON; no-input next is automatic only when it has a plugin event, otherwise manual even with HERDR_PANE_ID. Extend criterion 4 to cover explicit target/--all with inherited event JSON. This preserves current interface behavior and resolves the design's contradictory classification rule.

2. Replace the suggested criterion-5 race fixture. The design proposes fake-herdr writing the pause during pane split/tab create. Main next dispatch already holds the global lock (`src/next.ts:1245`), with allocation and agent delivery inside it (`src/next.ts:1250`, `src/next.ts:655`, `src/next.ts:544`, `src/next.ts:576`). Writing pause directly from that fake bypasses the required pause command's lock and proves a race that legitimate callers cannot produce. Invoking the actual pause synchronously inside the fake would deadlock while next waits for that fake to finish. It also misses the actual unlocked merge-dispatch interval (`src/next.ts:1332`, `src/next.ts:1115`). Exact fix: replace that proof guidance with two real CLI processes using the same global lock. Deterministically hold an automatic pass before its final locked launch section, let the actual pause command finish, then release the pass and verify no allocation/start/prompt follows. Separately, hold an automatic launch while it owns the lock, start pause concurrently, verify pause cannot acknowledge until the launch releases the lock, then verify later automatic work is suppressed. A fake may provide barriers but must not write pause state outside the command. Keep criterion 5's observable acknowledgement guarantee.
