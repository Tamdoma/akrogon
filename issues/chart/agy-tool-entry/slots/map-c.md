# Territory map for #164 (slot C)

## Mechanism
- `src/seat.ts:startSeat` wires three seat-only channels: `claude` (`CLAUDE_CODE_SHELL`, `CLAUDE_CODE_TOOL_MEMORY_LIMIT=none`), `pi`/`codex`/other (`BASH_ENV`), and `agy` (`agyPath` prepends `<homePath()>/tool-entry` to `PATH` inside `seatWrap`), plus `AKROGON_SEAT_CGROUP` and `AKROGON_SEAT_PID`.
- `src/run-check.ts:constructedEnv` (`copied`) and `src/verify.ts:launchPass` (`passForwarded`) already drop `CLAUDE_CODE_SHELL`, `BASH_ENV`, `AKROGON_SEAT_CGROUP`, and `AKROGON_SEAT_PID`, so non-`agy` seat wiring never reaches checked runs. Only `PATH` is forwarded verbatim — in `constructedEnv` (also called by `src/next.ts:ensureWorktree`), `launchPass`, `src/land.ts:launchLand` (reached from an `agy` seat via `akrogon phase` -> `src/next.ts:mergeWake` -> `mergePass`), and `package.json` `scripts.test` (`-E PATH`).
- Inside `tests/tool-entry.test.ts`, `scopeScript` exports `AKROGON_SEAT_CGROUP="$root"` and runs bare `bash`, hitting the host `<home>/tool-entry/bash`. That fails unwired reference `r` (placed into `tools/t-`) and silently runs `f`/`a`/`s`/`u`/`d`/`x`/`xref`/`w`/`wref`/`outside` through the host wrapper instead of plain `bash`. Separately, `src/tool-cgroup.ts:realBash` only skips `resolve(home, 'tool-entry')`, so `refreshToolEntry(scratchHome)` bakes the host wrapper into `<scratch>/tool-entry/bash`.

## Candidates
- **(a) Test's own env (`tests/tool-entry.test.ts` stripping entry dir or calling real `bash`)**
  - Class: Does not remove the class. `<home>/tool-entry` still leaks into `run-check`, `verify`, `land`, consumer repos, and every other test; fixing only `r` leaves the rest of `scopeScript` and `realBash` hitting the host wrapper.
  - Breaks/invites: Breaks nothing (`claude` seats, `land`, checks unaffected); invites per-test whack-a-mole whenever any test or repo check runs `bash` or `refreshToolEntry`.
  - Cheapest proof: Run `tests/tool-entry.test.ts` with a scratch `refreshToolEntry` dir prepended to `PATH` (red on `r`, green after).
- **(b) `tests/isolation.ts` preload (strip entry dir from `PATH` for all Bun tests)**
  - Class: Removes the class only for `akrogon`'s Bun suite (including direct `bun test` and `bun run test`, provided the caller's entry dir is captured before `setEnv('HOME', ...)` overwrites `HOME`), not for `run-check`/`verify`/`land` in consumer repos or non-Bun checks (`setup`, `format`, `typecheck`).
  - Breaks/invites: Breaks nothing (`claude` seats, `land`, and `tests/tool-entry.test.ts`'s own `PATH="$ENTRY:$PATH"` are unaffected). Invites `agy`-only failures in other repos' checked runs later.
  - Cheapest proof: Run `tests/tool-entry.test.ts` (or a `tests/isolation.test.ts` child probe) with `<home>/tool-entry` prepended to `PATH` (red before, green after).
- **(c) Strip entry dir from `PATH` in `src/run-check.ts:constructedEnv` and `src/verify.ts:launchPass` (plus `src/land.ts:launchLand`)**
  - Class: Removes the checked-run leak class across every repo (`run-check`, `verify`, `ensureWorktree` setup, and `mergeWake`-triggered `land`), restoring parity with `CLAUDE_CODE_SHELL` and `BASH_ENV`. Only direct `bun test`/`bun run test` bypassing `run-check`/`verify` stays outside this boundary (same as `BASH_ENV` on `pi`/`codex`).
  - Breaks/invites: Breaks no check (no check legitimately needs the seat wrapper: checked runs execute outside the seat scope root with `AKROGON_SEAT_CGROUP` already stripped, so the wrapper is always inert; `readiness.yaml` probes mint their own scratch dir). Leaves `claude` seats untouched and protects `land` runs launched via `mergeWake` from an `agy` seat. Must filter canonical/resolved paths for both `homePath()` and `~/.akrogon` in case `AKROGON_HOME` is overridden.
  - Cheapest proof: Free CLI test in `tests/run-check.test.ts` and `tests/display-env.test.ts` calling `refreshToolEntry(f.home)`, passing `PATH=<f.home>/tool-entry:...` into `run-check`, `verify` (`passArgv`), and `next` (`landArgv`), asserting the entry dir is absent (red before, green after; `<1s`), plus `run-check` executing `tests/tool-entry.test.ts` with the entry dir on `PATH`.
- **(d) Seat wiring (`src/seat.ts:startSeat` or `src/tool-cgroup.ts:entryTemplate`)**
  - Sub-shape (d1) switching `agy` off `PATH` (e.g. to `BASH_ENV`): unproved on live `agy` (needs a paid charting proof; `design.md` Q3 rejected `BASH_ENV` for `agy`), breaks `tests/tool-entry.test.ts`'s `agy` argv assertion, and risks placing `agy` hooks/MCPs.
  - Sub-shape (d2) keeping `PATH` on `agy` while `<entryDir>/bash` strips its own dir from `PATH` before `exec`: removes the leak for every child of `agy`'s bash tool shells (including direct `bun test`, `run-check`, `verify`, `land`) without affecting `claude` seats (`CLAUDE_CODE_SHELL` never puts `entryDir` on `PATH`) or `P-entry-agy`. Still misses any non-bash direct exec by `agy` (or caller-injected `PATH`), adds bash `PATH`-editing edge cases (empty segments, symlinks) to every tool shell, and breaks the wrapper's transparent-env contract.
  - Cheapest proof: For (d2), run `<entry>/bash -c 'printf %s "$PATH"'` with `PATH="$ENTRY:$PATH"` asserting `$ENTRY` is stripped (red before, green after); for (d1), requires a paid live `agy` probe.

## Other tests with the same exposure
- `tests/tool-entry-tracing.test.ts`: calls `refreshToolEntry(home)` on a scratch dir; `src/tool-cgroup.ts:realBash` only skips `resolve(home, 'tool-entry')`, so host `~/.akrogon/tool-entry/bash` is baked as the shebang and `exec` target of `<scratch>/tool-entry/bash` (masked today because `AKROGON_SEAT_CGROUP=` is empty and installed wrapper matches HEAD, but breaks or tests the wrong wrapper when editing `entryTemplate`).
- `tests/tool-entry.test.ts` beyond `r`: `f`, `a`, `s`, `u`, `d`, `x`/`xref`, `w`/`wref`, and `outside` all invoke bare `bash`, and `b`/`c` plus case 2 (`startSeat`) call `refreshToolEntry` on scratch homes (`realBash` chains to host wrapper).
- `tests/tool-kill.test.ts` (`spawnScope`, `s3Payload`, `scopeEnv`, refusal `bash -c`): runs `bash` on inherited `PATH` inside real delegated scopes (inert only because `AKROGON_SEAT_CGROUP` is unset/mismatched).
- `tests/lessons.test.ts` (`bash -c` with inherited `PATH`), `tests/hc-fixture.ts:hcCore` (`corePath` propagates `process.env.PATH` into `bash` terminals in `tests/watch-timer.test.ts`, `tests/watch-consult.test.ts`, `tests/door-exchange.test.ts`, `tests/recovered-seat.test.ts`, `tests/hc-fixture-retry.test.ts`), and `tests/e2e/{watch-tier,tier,watch-consults-body}.ts` / `tests/e2e/watch-live.e2e.ts`.

## Recommendation
- **Pick (c)**: add one `stripToolEntryPath` helper in `src/tool-cgroup.ts` (reusing `realBash`'s resolved+realpath matching against `homePath()` and `~/.akrogon/tool-entry`) and apply it in `src/run-check.ts:constructedEnv`, `src/verify.ts:launchPass`, and `src/land.ts:launchLand`.
- **Reason**: Fixes the defect at the exact env-sanitization boundary that already strips `claude` and `pi`/`codex` seat wiring, eliminates the leak across every repo and `mergeWake`-launched `land` runs, keeps `tool-entry/bash` transparent and `P-entry-agy` intact, and needs no paid proof.
- **Cost**: ~25 LOC across `src/tool-cgroup.ts`, `src/run-check.ts`, `src/verify.ts`, `src/land.ts` plus fast free tests (`<1s`). Optional add-on if direct `bun test` from an `agy` seat must also pass: also skip `homePath()`/`~/.akrogon` entry dirs in `realBash` and before `setEnv('HOME', ...)` in `tests/isolation.ts` (~10 LOC).
