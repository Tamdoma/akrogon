# Slot B leaf review: disagreements

1. **The direct-review path needs an explicit change.** The draft design says “The direct route needs no special text” because `<chart>/direct/plan.md` exists, but `skills/check-issue/SKILL.md:101`, section “Standalone review”, explicitly substitutes the chart's brief and design wherever the review rules name `plan.md`. Thus adding the canonical rule in plan.synthesis and changing check.review does not make direct B review the command correction recorded in the direct plan. A corrected command can still be judged against the original brief invocation, or its recorded justification missed. Add “Standalone review” to the owned sections and require direct B to use `<chart>/direct/plan.md` for the proof mapping and correction evidence. This follows Taken 1a's requirement that B judge A's correction and fixes the draft's direct-route exclusion without a second rule definition.

2. **A merge-origin command correction also needs an exception to the old-command replay requirement.** `skills/implement-issue/SKILL.md:82`, section “check.fix”, requires the reproducing command to use the recorded runner, requires its rerun after repair, and forbids returning to check.review while that rerun is red. If merge hands A a wrong proof command, A can correct the plan and prove the unchanged result, yet the old reproducing command can remain red for precisely the unsuitable invocation being replaced. Criterion 2's change to the failure ending does not resolve that earlier prohibition, and criterion 3 explicitly promises this merge handoff. Name this paragraph in the design and require it to distinguish a corrected proof invocation from a product repair: keep the original failure evidence, rerun the valid replacement with unchanged coverage, and permit review under the canonical rule. Required configured checks must retain their existing receipt and known-red requirements. This is within the already owned check.fix section, but leaving the replay instruction unchanged preserves the operator stop on this path.
