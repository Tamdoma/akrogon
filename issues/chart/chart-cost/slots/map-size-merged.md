Options
- O1 (A,B,C) Bound by the map's job. The map names each fork, what it decides and why it changes the outcome, the inspected evidence that shows the fork exists or orders it, lifetime pitfalls with the fork that owns each, practitioner questions, fog and what was not measured. Options for a fork and the research behind them wait for that fork's round. Peers return the map as notes.

  - Where slots differ inside O1: C wants one line per item, with option prose and tables excluded by name. B wants no fixed count of words, sources or forks, and wants an outside fact inspected at map time when it changes scope, a fork's existence or the order.
