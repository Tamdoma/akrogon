# Slot B: proof of saving

1. Pick: a small, read-only transcript report, run after each of the first three completed charts following shipment. A records the chart-to-session links and stage boundaries during the chart, then runs the report and presents one compact comparison. Keep the record and report in the chart. No dashboard, lifecycle state, background watcher or mandatory cost gate.

The smallest useful input is each seat's harness/session identifier, actual model and effort, skill revision, notes format, chart start/end and timestamp boundaries for the opening map, each fork and handoff. A records changes of session/model/effort rather than assuming pane-start settings held throughout. Record whether these settings were stated at open. Boundary entries point to the corresponding prompt/operator message or return artifact. A should identify boundaries as the exchanges finish, without an extra peer turn.

The report shows:
- Per seat and stage: input, cached input, cache write where available, output including reasoning, tool/web calls, active turn duration and dollars with measured/estimated/unmeasured labels. Opening-map figures stay separate from fork and handoff figures.
- Per fork: total usage across A/B/C through notes, merge, rebuttals, any focused final check and restatements. Report elapsed time from the operator's preceding answer to the complete next round, plus the additional restatement interval when present. Operator idle/approval time is separate. Parallel seat durations are not added to claim elapsed time.
- Per chart: total usage and cost by seat, fork count, restatement requests, map cache metrics, later cache-read share where dollars are attributable, B input per turn, and handoff output. A records actual bytes written before/after draft review and whether finalized files were transferred. Final file sizes alone do not measure writing.

Reason: repeated manual transcript discovery already consumed several dollars of A's tokens. Explicit links plus deterministic arithmetic address that recurring work without replacing quality judgment. Cost to build: an estimated 2-4 engineering hours for one scoped reporter, two transcript readers, boundary input and meaningful accounting fixtures. Cost to run: estimated seconds of local computation, no model calls for parsing, plus roughly 5-10 minutes of A's boundary/quality review per chart and a short summary turn. These estimates are unmeasured. No additional chart replay is required for the initial observations.

4. Pitfalls:
- Double-count streamed Claude blocks or cumulative Codex snapshots. Deduplicate Claude assistant usage by message id with consistency checks. Use Codex cumulative differences across recorded boundaries, never sum cumulative snapshots or add reasoning tokens to output again. Verify accounting against known small trace fixtures and session totals. Missing boundaries or counter resets must be explicit errors or incomplete results.
- Allocate a session's final cost-state to an arbitrary chart. Report session totals as reconciliation only. For chart dollars use attributable records where available or an explicitly sourced rate estimate by usage class/model, otherwise mark unmeasured. Preserve token totals even when dollars are unavailable.
- Hide startup, compaction, review or restatement costs. Include all attributable calls within chart boundaries and flag unresolved attribution. Record interruptions and operator wait separately rather than treating them as agent slowdown.
- Declare savings while losing decisions or producing worse contracts. A reviews the rounds and final contracts for material omissions and retained locks. Restatements are a visible usability signal, not a complete grade. Show defects alongside cost/time. Do not pass quality from exact wording or layout.
- Mix model, effort, workload and skill changes. Compare like stages/seats with their actual settings, show all three charts and ranges rather than one favorable average, and report historical comparisons as observational. If a causal claim matters, propose a matched replay separately. No automatic experiment or global model setting follows from this report.
- Leak transcript contents or credentials. The reporter emits identifiers, timestamps and numeric aggregates, not raw message/tool bodies or secret values.
