## Findings and stocks

**F1 — Optimize total context exposure while preserving independent judgment.** L3 is `S = Σseat Σcall context(call) = Σseat calls × average_context`. Cache reads count. Removing Δ context early saves approximately `Δ × subsequent calls until compaction`, not merely Δ. Removing a needless model call saves that call's whole context. These estimates overlap and must not be added.

**F2 — Use fixed measurement boundaries.** Study B stops at transcript line 3567, 2026-10-17 16:49:24Z: **479 requests, 67.922M input, 141,800 average**, not 993 assistant rows. INTAKE's later snapshot is 494 requests/69.3M. Neither is a contradiction. Study C attributes consultant exchanges by brief. Legacy overlapping chart windows cannot be summed or equated to that attribution.

## Research and lifetime questions

All sources read 2026-10-17. Practitioner synthesis: Anthropic's applied agent team, describing Claude Code experience, favors targeted retrieval and compaction that retains critical state. Yichao “Peak” Ji, reporting four iterations of Manus's agent framework, favors recoverable filesystem context and stable cache prefixes. Both favor selective context with recoverable evidence. ## Common leaf proof

**V1 — Matched work.** Freeze source revision, intake, locks, models/effort and the operator-answer sequence. Compare baseline/change on the same shape: independent maps → one material fork → blind notes → merge → both rebuttals → correction check when applicable → leaf review → handoff records. Use a process-edit case and an ordinary case for staged loading. Do not treat today's different charts as a controlled experiment.

**V2 — Accounting.** Count all A/B/C requests, native average context and total S through completion, including setup, restarts, recovery, retries and late review. Preserve chart spans, shared-map ownership and distinct-message grouping (`chart-usage.ts:181–205`). Report observed delta separately from forecast. Cache/output/elapsed figures explain tradeoffs, not replacements for L3. Any new live criterion must name existing machinery and session/time bounds before handoff.

**V3 — Functional parity.** A thinking reviewer checks material findings, independent-only evidence, correct attribution, rebuttal objections, late corrections, authority, stop points and required records. Mechanical checks validate file/state presence, identities and transitions. No exact prose match. Include a deliberately distorted merge and a missing peer return so a cheaper run cannot pass by losing dissent or ignoring failure.

**V4 — Adoption.** Start with K2/K3/K5 and the concrete duplicate-read case. Measure their combined net gain before considering K4/K7. A failed equivalence trial supplies no saving claim and does not weaken L1/L2.
