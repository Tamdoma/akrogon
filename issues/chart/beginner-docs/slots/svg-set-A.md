# A notes — svg-set

Q1 pick (a): animate only where the point is order or a loop. Overview (README), life of one change (review ⇄ fix loop is the thing beginners miss), chart door (questions go out, answers come back, contract comes out). Static: ways to run work (side-by-side comparison, no order), folder map. Reason: operator asked for motion "only to make them useful". Cost: ~5 SVGs to keep in sync with behavior.
Rejected (b): motion on every page is noise and multiplies upkeep. Rejected (c): one picture cannot show the review loop or the chart door.
Q2 pick (a): own solid background card. Reason: inside an <img>, prefers-color-scheme follows the browser/OS preference, not GitHub's theme setting, so (b) shows dark-on-dark when a user forces GitHub dark on a light OS (model-knowledge, low confidence; B to confirm). (c) <picture> with GitHub theme media works (GitHub changelog 2022-05-19) but doubles every file. Cost of (a): a light or dark card stands out a little on the other theme.
Q3 pick (a): hand-written SVG, CSS @keyframes, system font stack, no external fonts or scripts, a prefers-reduced-motion rule that shows the full final picture, every label readable in the static state. Reason: no toolchain (package.json has none); CSS animation is what widely used README SVG services ship (Jonah Lawrence's readme-typing-svg, Anurag Hazra's github-readme-stats, both render through GitHub's camo image proxy). Rejected (b) SMIL: works, but has no reduced-motion hook of its own. Rejected (c): a generator is a new tool to maintain for ~5 files.
Pitfall: text in SVG uses the viewer's fonts → labels overflow on other systems. Removed by short labels and generous box widths, checked in the review screenshots.
Q4 pick (a): run the probe at charting. Tamdoma/akrogon is public and ivanjuras has push (gh api, 2026-10-23). Smallest reversible write: push branch svg-probe-<date> holding one test SVG + one .md, view on github.com (light, dark, reduced motion) with blepsis/chromium, delete the branch, confirm with git ls-remote. Effect: a public branch for a few minutes. Cost: a few minutes and one approval.
Rejected (b): practitioner evidence covers external-URL images; repo-relative SVG goes through raw.githubusercontent with a sandbox CSP — likely fine, not proven. Rejected (c): finds a failure after all pictures are built.
Extra question: none.
