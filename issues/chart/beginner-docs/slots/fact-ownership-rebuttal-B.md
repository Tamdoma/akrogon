# Rebuttal B — fact-ownership

Disagree with retaining all documentation retirement bans unchanged. tests/hold-retired.test.ts applies raw regexes such as /\bunhold\b/ to every Markdown file under docs, and tests/run-permit.test.ts rejects /run permit/i in selected docs. These checks cannot distinguish an obsolete instruction from an accurate statement that the feature was removed. They therefore constrain prose rather than prove retirement. Evidence: both test bodies inspected 2026-10-23; commit 7efe3d67 removes a comparable guide-wording gate and assigns semantic assessment to review. Preserve runtime refusal/removal regression tests. For the docs assertions touched by this restructure, retain only an explicitly required prohibition on publishing stale executable syntax, or remove the wording expectation with its reason. Do not add a complex prose classifier or weaken runtime retirement coverage.
