#141: Limit the soft reset to a WIP commit in a detached leaf-worker checkout. The same template goes to standalone workers on the current branch, where “Standalone” requires tests committed before code. Resetting to the start and making one commit would erase that separation. For a resumed leaf unit, “start HEAD” must mean the original unit base, not the replacement worker’s starting tip.

#142: “One other line hides every citation” is false. In a local Git probe, a final paragraph containing a Test-Change trailer, a flush-left prose line and a Signed-off-by trailer still returned both trailers. Recommend a reliable writer form, not a false parser rule: “Use one line per citation in a final paragraph containing only trailers.” Do not make a new prose fragment a test contract. Test the path, refusal and successful repair; have review judge the explanation.

#143: Q5 treats every unsourced script check as contradicting standing design. The installed line requires a one-right-answer source for a proposed script check **on model output**. Narrow the rewrite trigger to that case; do not rewrite ordinary file-existence or literal-reference checks merely because their histories lack a source field.
