## Why the shell receipt is missing

**F1. The failure is in live delivery before a verified tick.** Five failures show a live Bun timer t2, parent t1, the space-containing root, a pin and a 30-second interval. The shell call logs contain the start check and no later check. The Claude and Codex transcripts named in the four timer argv records contain the start request and no subsequent tick request. The missing receipt is a valid failure of criterion 11. The displayed null status and turn 0 belong to **t2**, the timer. They do not establish t1's state. Evidence: I/check-watch-live-{claude,codex,pi}-shell-*.log, I/e2e-*-shell/*calls.log, W/tests/e2e/watch-live.e2e.ts (`waitDue`).

**F2. The leading product defect is a readiness gate with no reliable shell signal.** At `eda8a876`, W/skills/watch-issues/scripts/timer.ts samples readiness only at interval boundaries, holds every due on null status and absorbs hc read/send errors. A failed process pin exits and removes t2. A receipt is written by tick.ts only after delivery and verification. P12/P13 establish foreground identity, not delivery. The five logs lack t1's boundary state and the send result, so they cannot distinguish skipped send from rejected or unsubmitted send. Earlier `turnDone` actually observed an idle turn before the failure. Evidence: W/skills/watch-issues/scripts/{start,timer,tick}.ts, W/tests/e2e/watch-live.e2e.ts at `83961ae8`, C/watch-any-harness/forks/timer-design.md P5/P7/P10–P13.

**F3. There is a design gap if a shell cannot expose readiness.** The staged timer accepts null as ready and waits by deadline without requiring turn advance. That can merge a tick into a busy turn and break criterion 4. Keep the foreground pin and first-step receipt. Use a free shell-hosted stand-in to record t1 status/turn, foreground, due, send result, received input and stamp in order, including a busy turn. Return to the chart if the required idle signal is unavailable. The agy-shell “t1 never finished turn 0” is a separate driver failure. Evidence: L/brief.md criteria 3–4, C/watch-any-harness/forks/timer-design.md Taken and Corrections, W/skills/watch-issues/scripts/timer.ts, I/check-watch-live-agy-shell-1795192659220-2969283.log.
