# Blind notes B: equality-rule

## Pick, reason and cost

- D1. Keep the ignored-path guard in shared `integrate`. Narrow its collision rule instead of adding separate checks to sync and self-update. Both routes already enter here before operator checkout changes. Git itself permits destructive overwrites, so removing the guard removes protection. Cost: retain the existing path-overlap calculation and enrich the incoming tree listing with mode, type and object ID.
- D2. Exempt an exact incoming leaf only when local filesystem type, raw content and Git mode match. For regular files, compare raw bytes through `git hash-object --no-filters -- <path>` against the incoming blob ID, after `lstat` establishes a regular file. Compare the owner executable bit with `100644` or `100755`, even with `core.filemode=false`. For symlinks, compare raw link-target bytes against the `120000` blob without dereferencing. Reject directory/leaf overlap, gitlinks and other filesystem types. Git mode does not include ownership, timestamps, ACLs or every POSIX permission bit. Cost: filesystem metadata plus content hashing for exact collision candidates only.
- D3. Preserve replay-path protection independently of incoming equality. Do not let an equal incoming entry waive a collision with paths touched by local commits being replayed, including ancestor/descendant overlaps. A path absent from incoming has no equality exemption merely because some historical blob matches. Cost: conservative refusals remain for replay overlaps. Supporting those would require proving the whole replay preserves the operator file and exceeds the reported incoming-file case.

## Rejected options

- O1. Remove shared protection and trust Git or self-update's `moveCheckout`: both actual Git move commands overwrite differing ignored files, including directory contents. The existing self-update equality branch runs only after `read-tree` fails, which these ignored collisions do not cause.
- O2. Put independent comparators in each move route: duplicates one policy across rebase and read-tree and moves sync's refusal after issue staging/commit unless carefully reordered. Shared preflight already supplies the required location.
- O3. Compare blob hashes alone: equal hashes do not distinguish a regular file from a symlink containing the same bytes, or executable from non-executable files. Hashing a symlink pathname can also hash its referent instead of its link text.
- O4. Use default filtered hashing or Git's clean status as equality: CRLF and LF can hash identically after normalization while their raw bytes differ. That contradicts the intake's byte-identical criterion.
- O5. Delete, force-add, stash or otherwise mutate ignored files to make checkout work: unnecessary for the equal case, and adds recovery and index changes before a refusal. The existing move commands already accept identical ignored files.
- O6. Apply incoming equality across the union of incoming and historical replay paths: loses the distinction between a final incoming leaf and temporary replay content. Matching one blob does not establish preservation.

## Pitfalls and what removes them

- R1. Silent data/type/mode loss: retain shared preflight and require the complete D2 match before permitting an exact collision.
- R2. Symlink dereference or mode blindness: use `lstat`, Git executable mode and link-target bytes. Test both file/symlink directions and both executable mismatch directions.
- R3. Filtered equality hides different bytes: explicitly disable filters for the raw comparison. Include an LF/CRLF mismatch test. Normal checkout filters may still transform an accepted raw-equal blob during Git's move, so this rule proves equality with the committed blob, not an absolute promise that Git preserves the worktree byte representation.
- R4. Replay deletes or replaces an apparently equal file: D3 keeps replay overlaps blocked. Retain the existing add-then-delete replay regression.
- R5. Filename parsing and directory overlap regressions: retain NUL boundaries, match incoming entries by exact path, and keep ancestor/descendant collision checks. Do not split filenames on whitespace or dereference a directory to compare its contents.
- R6. A mixed batch partially changes before rejection: compare every candidate before calling the move callback. Add a batch containing both equal and differing ignored files and assert checkout/index/records are unchanged on refusal.
